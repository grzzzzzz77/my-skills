# 简历诊断清单 — 专科 / 高职 口径（vocational track）

> 仅用于专科 / 高职 track（模块 5）。本科走 `resume-checklist.md`。
> 核心差异：专科简历**重证书、重实操、重对口实习，弱化 GPA / 论文 / 学术**。
> HR 看专科简历，第一眼找的是"有没有对口的硬证书、能不能上手干活"。

## 使用说明（与本科一致：速览 + 深挖）
1. **先出「简历健康度速览」**：对下面 7 个维度各给 **✅ 强 / ⚠️ 中 / ❌ 弱**，用一张小表呈现（维度 | 评级 | 一句话结论），**表格后补一句总评定调**。
2. **再深挖标红/标黄的 3-5 项**：每条给"问题是什么 → 为什么影响求职 → 具体怎么改"，必须指向简历**具体内容**。

> 不要把条目全倒进报告——速览给全貌，深挖只挑真正短板。

> **重心自适应（重要，同本科）**：先看速览分布定着力点——
> - **强简历（≥5 ✅，证书齐/实操实）**：不硬凑弱项，转"优势讲到顶 + 提升点"，把篇幅让给升学/就业研判与资源模块。
> - **空 / 弱简历（大半 ❌，无证书/无顶岗/无实训）**：不逐条列缺失，重心转"先去考证/找顶岗/攒实训"，抓手让给行动建议。
> - **中等简历**：诊断主场，正常深挖。
> ⚠️ 内容太少的简历，"真实性一致性"维度可能因"无内容可夸大"而显 ✅——别让单维误导，靠**总评定调**。

> **雇主类型适配**：专科同样分雇主类型（见 `employer-type-strategy.md`）——冲**国企技术岗/考编**要突出
> 学历层次、技能证书、政治面貌、获奖；冲**民营工厂/制造企业**突出对口工种证书+顶岗实操即战力；
> 冲**连锁/现代服务私企**突出沟通、对口实习与稳定性。诊断侧重随目标雇主调整。

> **改法与示范**：每条"具体怎么改"的范式（STAR 落地、专业动词、加粗证书/设备/产出）以及 before→after 改写示范，
> 统一见 `resume-rewrite-craft.md`。核心红线：**只扩写不编造、缺数字留占位**。

## 维度 1：证书与技能资质（专科最硬通货，优先级最高）
- [ ] **缺对口职业资格 / 技能等级证**
      影响：专科求职证书是敲门砖，缺对口证（护士执业资格、电工证、会计证、教师资格、CAD/BIM、
            1+X 职业技能等级证、Adobe、计算机/英语等级等）会被直接刷
      改法：列出该专业/目标岗最该考的 1-3 个证 + 考取建议（接模块 7 时间线）
- [ ] **证书埋没在简历末尾 / 没分级**
      影响：HR 扫简历几秒，硬证书放末尾等于没有
      改法：证书单独成栏、靠前呈现；技能注明熟练度（精通/熟练/了解）与对应设备/软件

## 维度 2：顶岗实习 / 对口实习（专科普遍有，最容易写废）
- [ ] **顶岗实习只写岗位名、没写实操内容**
      影响："在 XX 厂顶岗实习"等于什么都没说，看不出会干什么
      改法：写清操作了什么设备/工艺/系统、负责什么环节、有无产出或数据
            （如"独立操作 XX 数控机床，日均加工 XX 件，良品率 XX%"）
- [ ] **实习与目标岗不对口 / 无实习**
      影响：方向散或零实习，竞争力弱
      改法：力争一段对口顶岗/实习；已有不对口实习则提炼可迁移的实操能力

## 维度 3：实训项目与技能大赛（专科的"项目经历"）
- [ ] **有实训 / 技能大赛但没写出来**
      影响：校内实训、技能竞赛是专科证明动手能力的好材料，漏写可惜
      改法：把代表性实训项目、技能大赛获奖（即使校级）写成条目，说明做了什么、用到什么技能
- [ ] 实训只写课程名、没写产出
      影响：看不出实际能力
      改法：写清做出了什么作品/成果、用到哪些工具设备

## 维度 4：求职定位与结构
- [ ] **方向不清 / 简历无定位**
      影响：HR 不知往哪个岗匹配
      改法：定 1 个主攻工种，把对口证书、实习、技能前置，做成方向明确的一版
- [ ] **套用本科简历模板、强行写 GPA / 学术**
      影响：专科简历堆 GPA、课程论文反而稀释了证书和实操的存在感
      改法：删掉无关学术内容，腾出版面给证书、顶岗实习、技能

## 维度 5：真实性与一致性（同样是扣分雷达）
- [ ] **时间线重叠 / 倒置**（顶岗实习、在校时间冲突或写反）
      影响：硬伤，显不严谨
      改法：逐段核对起止时间，确保不冲突
- [ ] 证书/获奖无法佐证、技能等级与描述不符
      影响：面试一问露馅
      改法：只写经得起追问的内容，证书写清等级与发证机构

## 维度 6：可读性与专业感
- [ ] 简历超一页、排版拥挤、错别字
      影响：细节暴露态度，HR 扫不到重点
      改法：精简到一页；证书/实习/技能清晰分区、加粗前置；通读校对错别字
- [ ] 条目不以动词开头、大段流水账
      影响：读起来啰嗦
      改法：每条用动词开头（操作/装配/维护/调试…），去掉口语化叙述

## 维度 7：升学并行场景（若学生走专升本）
- [ ] **走升学但没准备"就业保底简历"**
      影响：只押升学、不备就业简历，专升本失败时被动（见 `report-structure-vocational.md` 模块 3）
      改法：备考同时按上面维度整理一版可随时投递的就业简历，作保底
