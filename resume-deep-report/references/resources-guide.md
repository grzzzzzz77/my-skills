# 「资源与下一步」模块写作指南（中性资源推荐方法）

> 用途：报告最后一个模块（本科 track 模块 7 / 专科 track 模块 8）的写法标准。
> 这个模块**取代了原来的"服务承接/转化"模块**，立场完全中性：给的是用户能**自己上手**的外部资源
> 和下一步行动指引，**不推销、不导流、不出现任何公司 / 老师 / 套餐 / 价格 / 联系方式**。

## 这个模块要做到的一句话
把前面几个模块分析出的**能力缺口和方向**，落成**"具体可获取、用户能自己去用"的资源 + 一两步马上能做的行动**。

---

## 五个硬标准（每一条都要守）

1. **具体、可获取**——不要泛泛"多学习、多实践、多考证"。要给得出**名字 / 类型 / 方向**的东西：
   - 好：「后端方向可主攻 MySQL 索引与 Redis 缓存，公开课可看慕课网/B站的系统课，权威资料读《高性能 MySQL》、官方文档」
   - 差：「建议加强数据库和缓存方面的学习」（等于没说）

2. **中性、不带货**——可以点名**公开、广为人知**的资源，但：
   - 不吹捧、不说"最好/首选/强烈推荐买"，不暗示某一家最优；
   - 同类资源给 **1-2 个示例**即可，让用户知道"这类东西去哪找"，而不是替谁导流；
   - 免费 / 付费都可提，但**不替任何机构 / 课程背书带货**，付费的注明"按需自行评估"。

3. **标时效与甄别**——证书、课程、政策、专升本类资源，一律提醒"**以官方 / 最新信息为准，注意辨别质量**"；
   不为任何资源的**效果打包票**（不说"考了就能进""学完必然涨薪"）。

4. **绝不编造**——这是底线，等同全 skill 的"绝不编造"原则：
   - 拿不准是否真实存在的**具体课程名 / 机构名 / 链接 / 书名**，**就不写**；
   - 改为给「**资源类型 + 怎么找**」（如"搜索本省教育考试院官网获取专升本最新公告"），而不是硬凑一个名字。
   - 只写真实、广为人知或本次搜索真实取得过的资源；没把握的降级为方向性指引。

5. **不暴露工具、不留半成品**——结尾**不加**"本报告由 xx 生成""免责声明""联系方式占位符""待补充"之类的字样；
   报告以一句平实、给信心但不浮夸的话自然收尾。

---

## 可选的资源类别（按用户情况挑 3-5 项，别全列）

> 不是清单模板，是"素材池"。结合这位用户的**方向、缺口、升学/就业选择**挑最相关的几类，每类给 1-2 个具体示例。

- **该补的能力 / 证书**：结合搜索 0（目标岗技能要求）或专科对口证，列**最值得补的具体技能点 / 证书**，说清对口性与优先级。
- **学习与提升资源**：针对缺口给**具体学习路径或资源类型**——公开课程平台、权威文档 / 经典书、技术社区、
  开源项目、刷题 / 练手平台、考证备考资料类型等。
- **求职渠道与信息源**：适合该方向的招聘渠道、行业信息源、可对标参考的岗位 JD 去哪看，方便用户自己持续跟进。
- **（专科·升学）专升本资源**：本省官方信息渠道（省教育考试院）、公开备考资料 / 课程类型、对口本科院校信息怎么查；
  **不编造机构/班次/价格、不暗示必须报班**（自学同样是正路）。
- **下一步行动**：用一两句把"看完报告后这周 / 这月先做哪一两件最关键的事"收口，与行动建议模块呼应、不重复。

---

## 写法示例（中性、具体、不带货）

> ✅ 推荐："针对你目标的 Java 后端岗，最该补齐的是 **Redis 缓存**与 **MySQL 索引优化**——这两项几乎是后端面试必问。
> 系统学习可以看公开课程平台（慕课网、B站均有成体系的免费 / 付费课，按需自选）和 **MySQL/Redis 官方文档**，
> 配套读《高性能 MySQL》这类公认的经典；练手可在 LeetCode 刷数据结构与算法。求职信息可持续跟进 BOSS 直聘、
> 牛客网（含大量真实面经与对标 JD）。**这周先做一件事：把简历按模块四的方向改完、投出前 5 家对口公司。**"
>
> ❌ 避免："我们的服务老师可以帮你优化简历并精准投递""报名我们的冲刺包包你拿 offer""加微信领取资料"
> ——任何推销、导流、联系方式、保证性承诺都不允许出现。
