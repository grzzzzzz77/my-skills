# 报告风格与话术指南

## 读者画像
主要读者：大学生本人，部分情况下家长也会阅读。
阅读场景：求职焦虑期，希望获得专业指导和信心。

## 语气原则
1. **专业但不居高临下**：用数据和逻辑说话，不用"你应该""你必须"
2. **诚实但有建设性**：指出问题时同步给出解决方案，不只泼冷水
3. **平衡而非一味乐观**：不说"企业抢着要""完全不存在问题"这类断言，
   而是说"在同层次求职者中具有竞争力""市场需求较为旺盛但竞争同样激烈"
4. **数据驱动**：尽量用具体数字而非模糊形容词。
   不说"薪资很高"，说"该方向应届生薪资中位数约 12-15k/月"
5. **不制造虚假紧迫感**：不用"再不行动就来不及了"的话术，
   而是客观说明时间窗口和节奏建议

## 措辞禁忌
- 避免："企业抢着要""稀缺人才""完全没问题""不好就业不存在"
- 避免：对学校/专业做绝对化的好坏判断
- 避免：承诺具体薪资数字（用区间）
- 避免：承诺"保就业""包入职"等保证性话术
- 避免：在中文里夹生英文词（如"您的 competitiveness 处于…"）。有对应中文就用中文（"竞争力"）；
  专有名词/技术栈（Java、Spring Boot、GPA）保留原文即可。
- **不要在报告末尾加"生成说明 / 技能署名 / 免责声明"之类的脚注**（如"本报告由 xx 技能生成…仅供参考…"）。
  这是给读者看的成品，不能暴露内部工具名，也不需要这类机器味的免责尾巴。
  数据时效与来源提示统一放在**报告开头「核心结论速览」下方的「信息说明」一行**（见 `report-structure.md`），
  那里已经中性地交代了"数据多新、来源何处、以官方为准"，末尾不必再重复。
  报告以最后一个模块（资源与下一步，本/专科均为模块 8）自然收尾即可。

## 收尾原则（报告末尾「资源与下一步」模块）
报告最后一个模块是**「资源与下一步」**——纯中性的资源指引，**不是服务介绍、不导流、不推销**。
逻辑链是：分析了你的情况 → 指出了可优化的地方 → **给你能自己上手的外部资源和下一步行动**。

> **具体写法见 `references/resources-guide.md`**：怎么中性推荐外部证书 / 课程 / 社区 / 工具 / 求职渠道，
> 怎么标时效与甄别、怎么做到具体可获取又不编造。承接时务必遵守。

**全程红线（整份报告，不只是末尾）**：
- **不出现任何推销、套餐、价格、"联系某某老师 / 我们能帮你做什么 / 找我们"之类的导流内容**。
- 不把任何服务写成产品、不替任何机构/课程带货、不暗示"某资源最好"或引导购买。
- 资源推荐**只做中性介绍**：点名公开、广为人知的资源即可，同类给 1-2 个示例，提醒"以官方最新信息为准、注意辨别质量"。
- **保护读者隐私（PII）**：报告正文**不回显手机号、身份证号、家庭住址、生日等敏感个人信息**——分析用不到这些。
  需要称呼时只用**姓名**；涉及地域分析时只用**城市 / 省份**粒度（户籍/生源地到省市即可），不写详细住址。
  简历里的 PII 仅用于本次分析、不写进交付报告。
- 收尾用一句平实、鼓励但不浮夸的话给信心即可（如"方向清楚、按节奏推进，你是有竞争力的"），
  **不喊口号、不做保证性承诺、不制造焦虑**。

注意分工（按现行 8 模块编号）：
- **模块 5（简历诊断）只做客观诊断**，模块 7（行动建议与发展规划）给"做什么、往哪长"，
  模块 8（资源与下一步）给"用什么去做"——三者分工不重复。
- 报告任何位置都**不插入销售内容**；末尾也只给资源与行动，不给任何联系方式或机构信息。

## 格式要求
- 使用清晰的标题层级（# ## ###）
- 关键数据和结论加粗
- **各模块篇幅以 `templates/report-structure.md` 中每个模块标注的字数为准**
  （单模块范围约 150-750 字，不要统一成同一字数）
- **全文目标约 2800-4000 字**（= 开头「核心结论速览」约 250-350 字 + 8 个模块篇幅之和约 2600-3700 字）。
  这是一份"深度但读得动"的报告，不是越长越好。
- **⚠️ 长度护栏（实测易超，务必主动收敛）**：生成时每个模块都容易写到目标上限的 1.5 倍，整篇很容易冲到
  5000-6000 字——那样就太长、读者读不动，**也让开头速览失去意义**。**每写完一个模块对一下它的篇幅上限**，
  超了就删冗余、并句、去重复（尤其「核心结论速览」必须压在半页内、「简历诊断」只挑 3-5 项别铺开）。
  **宁可精炼到位，不要为凑深度注水。**
