# 求职深度分析与发展规划报告 — 专科 / 高职 模块结构模板（vocational track）

> 本模板**仅用于专科 / 高职学生**（degree = 专科/高职）。本科及以上走 `report-structure.md`。
> 由 SKILL.md「§1.6 学历路由」分流进入。
> 本报告**直接面向求职者本人**，是一份纯分析与规划交付物，**不含任何推销 / 服务导流内容**，
> 以"资源与下一步"自然收尾（给可自己上手的外部资源），而非把读者导去任何付费服务。

报告标题格式：{school}{major}（{graduation_year}届）{target_city}求职升学分析与发展规划报告

**与本科 track 的根本区别（务必先理解）**：
专科报告的主轴**不是"怎么就业得更好"，而是先替学生回答"先升学还是先就业"**，并最终落到
**"升学 + 就业并行、用就业给升学打保底"**的策略上。本 track 与本科 track **对称为 8 模块**，
区别在**第 3 个"研判"核心模块**：本科是"求职路径与策略研判"，专科是**"升学 vs 就业 路径研判"**；
其余模块也都换成专科口径。

共 **8 个模块**：1 画像 → 2 竞争力定位 → **3 升学 vs 就业 路径研判（核心）** →
4 目标市场 → 5 简历诊断 → 6 政策福利 → 7 行动建议（升学/就业并行时间线 + 中长期成长）→ 8 资源与下一步

核心原则同本科：**有数据用数据，没数据降级兜底，绝不编造**；专升本政策、考试时间、薪资等
**必须运行时搜索取真实数据**，不得凭印象写死。

## 报告开头：核心结论速览（写在模块 1 前，半页以内）

> 整份报告的"封面答案"——写在所有模块之前，让读者第一眼就看到自己的处境和最该做的事，
> 不必读完 8 个模块。**它是后面各模块结论的浓缩，不引入新内容、更不编造。**

包含四小块，总计**半页以内、短而准**：
1. **一句话定位**：你现在处于什么处境（年级/是否应届 + 升学 vs 就业的初步倾向 + 主攻工种方向）。
2. **3 条最关键发现**：从升学/就业研判、市场、简历里挑出最该知道的 3 点（含 1 条优势、1-2 条短板）。
3. **本周就能做的 3 件事**：从行动建议里提炼最该立刻动手的 3 个具体小动作（如确认本省专升本报名节点、补考某证）。
4. **方向一句话**：「升学 + 就业并行，以就业给升学打保底」落到这位学生身上具体是什么。

写作要点：
- **先写完后面 8 个模块，再回头浓缩成这段**，必须与正文一致、不得出现正文没有的判断。
- 重心随简历强弱走（与模块 5「重心自适应」一致）：证书齐/实操实落"优势 + 提升点"，空/弱落"先去考证/找顶岗"。
- 只放结论与动作，不堆形容词、不打包票、不编造。

### 信息说明（紧跟速览，一行小字）

用**一行小字**交代信息时效与来源：
- 写明本报告市场 / 专升本政策 / 薪资数据的**采集时间**（如"数据采集于 2026 年 6 月"）与**主要来源类型**
  （公开招聘平台、本省教育考试院等官方渠道），并提示**具体节点 / 数字以官方最新公告为准**。
- 这是**中性的信息说明，不是机器味免责尾巴**——不暴露工具名、不写"本报告由 xx 生成 / 仅供参考"之类字样。

## 模块 1：个人画像总览
篇幅：150-200 字
数据来源：用户简历

内容：
- 概括核心背景：学校（高职/专科）、专业、**几年制 / 当前年级**、毕业年份、目标城市
- 列出简历关键亮点：**职业资格证 / 技能等级证、顶岗实习、技能大赛、实训项目**（专科口径，不看 GPA/论文）
- 明显缺失（如无任何证书、无实习）客观提及

写作要点：
- **开头先称呼问候学生**（"XX 同学，您好："），点明"这是专门为你（学校·专业·届别·目标城市）整理的报告"。
- **必须明确学生当前年级 / 是否应届**——这是模块 3 判断"专升本还来不来得及"的前提。
  若简历只给了毕业年份，结合当前日期推算年级（多数为 3 年制：毕业当年=大三/应届）。年级不确定时，
  在模块 3 提示"专升本可行性取决于当前年级，请向学生核实"。
- 客观陈述，不做价值判断。

## 模块 2：竞争力定位
篇幅：350-500 字
数据来源：`references/vocational-schools.md`（运行时搜索院校层次）+ 简历 + 搜索 0（专业对口岗位）

内容：
- **院校层次**：按 `vocational-schools.md` 的方法**运行时搜索**核实该校在高职体系中的定位
  （双高计划 / 国家示范性·骨干高职 / 省级示范 / 普通公办 / 民办），给出本地企业认可度判断。
  **不暴露内部档次编号**，口径如"该校为双高计划建设单位，在高职院校中处于第一梯队，本地认可度较高"。
- **专业匹配度**：专科专业普遍**对口性强、指向具体工种**（数控/护理/电商/学前教育/轨道交通等），
  说明该专业在目标城市对接哪些岗位。
- **技能与证书资产盘点（核心，必须定式化、不能泛泛）**：把简历里的**具体证书、实训、顶岗实习**
  逐项对照目标岗（搜索 0 的核心要求），归成三类——
  - **硬通货证书 / 直接命中**：职业资格证、技能等级证（1+X）、专业对口证（如护士执业资格、电工证、
    会计证、CAD/BIM、Adobe 等）——是专科求职的"敲门砖"，简历必须前置突出。
  - **可迁移的实操经验**：顶岗实习、实训项目、技能大赛——说清"它证明了你能上手做什么、怎么往目标岗讲"。
  - **弱相关 / 待补**：与目标岗重叠低的，点明应弱化；**完全缺证书 / 缺实习的，直接列为缺口**（改法归模块 5）。
- **应届身份**：专科应届身份对**统招专升本（多数省份仅应届可考）**和校招、政策申领都是关键权益，务必珍惜。

写作要点：
- **核心是"证书 + 实操资产盘点"那一段：必须点到简历里的具体证书名和具体实习/实训名**，
  给出"对目标岗价值高/中/低 + 可迁移点"判断，不要只说"动手能力强""实习经验丰富"这类空话。
- 与模块 5 分工：模块 2 做**价值定位**，模块 5 做**简历具体改法**。
- 若院校不在搜索可核实范围，用"普通公办/民办高职通用口径"兜底，**不编造档次**。
- 不做绝对化判断（专科不等于差，技术工种实操强反而吃香——见模块 4）。

## 模块 3：升学 vs 就业 路径研判（专科报告的核心；与本科模块 3"求职路径研判"对位，但内容是专科特有的升学研判）
篇幅：450-650 字（本模块要写"实"，是整份报告最有价值的部分）
数据来源：搜索 5（专升本**时间节点 + 报录比/竞争**，运行时按省查）+ 沉淀框架 `vocational-zhuanshengben.md`
+ 模块 2 的学业底子判断 + 学生年级/咨询时间 + 家庭经济承受力（如学生提供）

> 这一模块的立场是确定的：**最终建议"升学 + 就业并行、用就业给升学打保底"**——
> 不是逼学生二选一。但在给出这个建议前，必须先**结合客观事实判断升学这条腿现在还可不可行、值不值**。

必须讲清楚以下三件事：

**① 升学（统招专升本）到底可不可行、值不值？——多维可行性研判（最关键，不能只看时间）**
> 统招专升本的**通用框架（资格/一次机会/时间规律/与自考成考区别）已沉淀在
> `references/vocational-zhuanshengben.md`，直接取用、不要重复查**；动态信息（本省当年精确节点、
> 对口院校、报录比）才走搜索 5。

**可行性要从下面四个维度一起衡量，缺一不可——只判断"来不来得及"是不够的：**

- **时间可行性（来不来得及）**：统招专升本**仅省内全日制应届专科生可考、一生一次**（退役士兵有例外），
  **报名远早于考试**（毕业前一年底至当年初报名、3—4 月统考）——**判断要盯"报名"节点**。
  把「当前年级 + 当前咨询日期」与搜索 5 查到的本省当年节点交叉判断：大一大二 → 时间充裕；
  大三/毕业当年 → 核对本省今年报名节点是否已过，**已过/已毕业 → 统招本年度已无机会**，
  只剩自考/成考（非全日制、第一学历仍为专科），如实说明区别，别让学生误以为还能考统招。
- **胜算可行性（能不能考上）**：结合**学生学业底子**（模块 2：成绩位次、英语/专业课基础）+
  搜索 5 查到的**本省该专业报录比 / 竞争激烈度**，对"考上的把握"给一个客观、不打包票的判断。
  底子弱 + 竞争激烈 → 如实说难度，要么更早投入、要么调整预期，**不画饼也不劝退**。
- **经济可行性（供不供得起、值不值）**：专升本不是零成本——**报班需要一笔培训费用（各机构、各地差异大，
  从数千元到上万元不等，以当地实际报价为准），自学则省钱但要够自律**；再加上备考期的时间与机会成本
  （可能少一段实习/收入）。把这笔钱和时间明确摆出来、对照家庭经济承受力，让学生和家长心里有数；
  **不替学生下"必须报班"的结论，也不贬低自学**。
- **意愿可行性**：升学是学生本人（和家庭）的真实意愿，还是只为逃避就业、被推着走？
  意愿不强的，点明"并行更稳"，**不硬劝升学**。

> 四维综合后给出研判档位（但都落到"并行 + 就业保底"，不是二选一）：
> **优先升学 + 并行** / **谨慎尝试、重心放就业** / **不建议硬上、以就业为主（可日后边工作边自考）**。
> ⚠️ 框架用沉淀、**具体日期与报录比绝不写死**：以搜索 5 查到的本省官方公告为准；查不到就提示
> "请以本省教育考试院最新公告为准"、按年级与底子给方向性判断，不编造节点、不编造录取率。

**② 升学与就业的关系——为什么要并行**
- 讲清两条腿的逻辑：**就业是升学的保底**。专升本有不确定性（竞争、一次机会），
  如果只押升学、失败了就两手空空、还错过了秋招/实习黄金期。
- **并行 = 备考专升本的同时，照常投递实习 / 校招**：考上了就去读本科（第一学历升级）；
  没考上，手里已有 offer / 实习，可直接就业，不至于被动。

**③ 并行的好处与节奏建议**
- 总结并行策略对这位学生的具体好处（结合其年级、底子与上面的可行性档位）。
- 给出粗略的节奏框架（详细时间线在模块 7）：什么时候以备考为主、什么时候必须同步铺就业。

写作要点：
- **全部结合客观事实**：可行性四维（时间/胜算/经济/意愿）逐一对照这位学生的真实情况给研判，
  不要套通用模板话，也不要只写"来不来得及"一个维度。
- **报班费用必须点到**：在经济维度明确提示专升本报班是一笔额外支出（数千到上万、以实际报价为准）+ 时间机会成本，
  让学生和家长把这笔账算进去；但不替学生决定报不报、不贬低自学。
- 立场清晰但不武断：**明确建议"并行 + 就业保底"**，同时尊重学生意愿（有人就是铁了心升学/就业）。
- ⚠️ **先确认 `zsb_status` 再定调**：本模块的方向取决于"学生是否已报考本年度统招专升本 / 在等录取结果"
  （应在 §1.5 确认关卡问过用户本人）。**尤其当用户正值毕业季、本省今年考试已结束时**，仅凭简历会默认其放弃升学——
  这会写错方向。已报考在等结果 → 按"准备入学本科"写；确认未报考/已放弃 → 按本模块"以就业为主、升学留作日后自考成考"写；
  **信息缺失时**默认就业为主线，并在本模块明确留一句"若你已报考、正在等结果，请补充说明，报告会按'准备入学本科'另作调整"的兜底。
- 诚实：升学可行性低（时间已过 / 底子弱 + 竞争激烈 / 家庭难负担）就如实说、把重心转就业，不画饼也不劝退。
- 不制造焦虑、不做"保过"承诺；报录比、录取率等**没查到就不写数字**。

## 模块 4：目标市场分析（就业这条腿）
篇幅：300-400 字
数据来源：搜索 1（市场与薪资，**专科口径**）+ 搜索 3（产业动态）

内容：
- 目标城市该专业对口岗位的供需概况——专科岗位多为**技术执行 / 操作 / 一线**层
  （技术员、运维、护理、数控、施工员、电商运营、幼教等）。
- 薪资区间（标注来源和时间，**用专科 / 大专应届口径**，不要套本科数字）。
- **正向呈现技术工种优势**：数控、护理、新能源、轨道交通、智能制造等**技能型紧缺工种**，
  实操强的专科生反而吃香、就业率高，要客观点出，不要一味唱衰专科。
- 校招 / 春招 / 顶岗实习转正等时间窗口；本地龙头雇主或对口产业园简述。
- 若学生倾向升学，可补一句"目标专升本院校/专业"在该方向的衔接（简要即可，详见模块 3）。

写作要点：
- 数据标注来源；搜不到具体数字用"据公开招聘数据，该方向需求较旺盛"兜底，不编造。
- 既说机会也说竞争。
- 方向未定时，对比 2-3 个对口工种的市场情况（方法见 `major-career-map.md`，按专科口径理解）。
- **雇主类型适配**：若已知 `target_employer_type`，结合 `employer-type-strategy.md` 点出该类型招聘节奏与形式
  （国企技术岗/考编有笔试、提前批早；民营工厂/中小私企全年滚动、看即战力、流程短）。未指定则就最可能投的类型简述。

## 模块 5：简历诊断（专科口径，健康度速览 + 深挖弱项 + 一条改写示范）
篇幅：450-600 字
数据来源：`references/vocational-resume-checklist.md`（7 维度池）+ 用户简历 + 搜索 0
+ `employer-type-strategy.md` + `resume-rewrite-craft.md`（改写范式与示范方法）

本模块**分三步写**（同本科），但**先按简历强弱定重心**：

> **重心自适应（重要，同本科）**：先看速览总体分布，再决定着力点——
> - **强简历（≥5 个 ✅，证书齐、实操实、定位清）**：不硬凑弱项，转为"优势讲到顶 + 1-2 个提升点"，把篇幅让给模块 3（升学/就业研判）与模块 8（资源）。
> - **空 / 弱简历（大半 ❌，无证书 / 无顶岗 / 无实训可诊断）**：不要逐条列缺失，点到关键缺口后**重心转向"先去考证 / 找顶岗 / 攒实训"**，抓手让给模块 7 行动建议；改写示范选唯一能改的即可。
> - **中等简历**：诊断模块的**主场**，正常三步深挖。

**第一步：简历健康度速览（一张小表 + 一句总评）**
- 按 `vocational-resume-checklist.md` 的 **7 个维度**（证书资质 / 顶岗实习 / 实训竞赛 / 求职定位与结构 /
  真实性一致性 / 可读性 / 升学并行），每维度给 **✅ 强 / ⚠️ 中 / ❌ 弱** + 一句话结论，用 Markdown 表格呈现。
- 评级基于简历**具体内容**，**重心在证书与实操**，弱化 GPA / 论文。
- 表格后**补一句总评定调**（如"证书与实操底子不错，主要补顶岗实习描述"或"简历偏空，当务之急是先考对口证 + 找顶岗"）。
  ⚠️ 内容太少的简历，"真实性一致性"维度可能因"无内容可夸大"而显 ✅——别让它误导成"简历没问题"，靠总评定调。

**第二步：深挖标 ❌/⚠️ 的 3-5 项**
- 只展开弱/中维度，每条给 **问题 → 为什么影响求职 → 具体怎么改**，指向简历具体内容
  （如"您的顶岗实习只写了岗位名，没写做了什么设备/工艺、有无产出"）。
- "具体怎么改"按 `resume-rewrite-craft.md` 的范式给（STAR 落地、专业动词、加粗亮点；专科尤其突出证书与实操）。
- 若学生走升学，诊断兼顾"就业版简历"（保底投递用）。

**第三步：一条 before→after 改写示范**
- 挑最有代表性的一条弱经历（顶岗实习/实训其一），按 `resume-rewrite-craft.md` 给示范：
  **原文：……** → **建议改为：……**（套 STAR 落地、专业动词、`**加粗**`证书/设备/产出），末尾一句话说明改了什么、为什么更好。
- ⚠️ **真实性红线**：只基于已写内容扩写/重组，**绝不虚构**；缺的量化（加工件数/良品率等）留占位让学生自己填，**绝不替他编**。
- 一份报告给 **1 条**示范即可（弱简历最多 2 条）；不逐条代写整份简历。

写作要点：
- 速览给全貌、深挖给抓手；**不把 7 维度的所有条目都倒进报告**。
- 语气建设性，"建议"而非"缺点"；信息不足以深诊时坦诚说明并给通用建议。
- **不出现任何推销字眼**（本 skill 全程无推销；模块 8 也只给中性资源，不导流）。
- **雇主类型适配**：若已知 `target_employer_type`，按 `employer-type-strategy.md` 调整侧重——
  冲**国企技术岗/考编**额外看学历层次/技能证书/政治面貌/获奖；冲**民营工厂/制造企业**看对口工种证书 + 顶岗实操即战力；
  冲**连锁/现代服务私企**看沟通、对口实习与稳定性。未指定则按通用 + 其最可能投的类型提示。

## 模块 6：政策福利提醒
篇幅：200-300 字
数据来源：搜索 2（政策信息）+ hometown

内容与写作要点：政策口径**因城市而异，不能默认"专科都能领"**。
- 所有政策来自搜索结果，不硬编码；标注"以官方最新公告为准"。
- ⚠️ **专科常被排除在头部人才补贴外，必须如实核对、别想当然**（已验证教训）：不少城市的应届
  租房/安家/购房补贴**以本科起步**（如苏州租房补贴只发博/硕/本，专科不在列）。**搜到学历门槛时，
  若专科不在适用范围，要明确告诉学生"这几项你大概率拿不到"，不能让学生误以为应届就能领**；
  并可点出"若后续专升本升为本科即可对应享受"，作为升学的附加好处。
- **不替学生判定"你符合申领条件"**：列政策 + 提示适用条件（学历门槛/户籍/生源地/社保/时限）+ 让其自行核验。
- 搜不到具体政策 → 给官方查询渠道（当地人社局官网）。
- 专科可额外留意：部分城市对**技能人才 / 紧缺工种**有专项补贴或落户加分（考取高级工/技师等），如搜到可一并提示。

## 模块 7：行动建议与时间线（升学 / 就业 并行）
篇幅：350-450 字
数据来源：综合以上模块，尤其模块 3 的研判结果

内容：
- **按模块 3 的研判分叉给时间线**，但都落到"并行"框架：
  - **升学可行（大一大二 / 本省考试未过）**：以备考统招专升本为主线（含报班与否、复习节奏），
    **同步铺就业保底**（关注顶岗实习/春招，准备一版就业简历），并标出本省专升本报名/考试的关键时间节点提醒。
  - **升学已不可行（时间已过 / 已毕业）**：重心转就业，给投递与顶岗实习转正节奏；
    若仍想升学，说明只剩自考/成考（边工作边读）这条路。
- 按时间维度组织：本月 → 未来 1-3 个月 → 毕业前。
- 含：证书补强（考哪些对口证）、简历优化方向（接模块 5）、投递渠道与节奏、面试/技能测试准备。
- **Plan B**：升学失败或就业受阻时的退路（如先就业再边工作边专升本/自考）。
- **中长期成长（1-3 年）简述**：无论升学还是就业，点出这条技术工种线**未来 1-3 年的成长台阶**——
  如从初级技术员/操作工 → 凭证书+经验晋升技师/带组/转管理或技术专精；升学成功则衔接本科后的方向。
  几句即可，让用户看到"几年后能走到哪"，不画饼、因人而异处如实说明。

写作要点：
- 具体可执行，不要"加油努力"式空话。
- 时间节点结合搜索 5（专升本）与搜索 1（招聘节奏），不编造日期。
- 始终体现"并行、就业保底"的总策略。
- 中长期成长落到**能力/证书/岗位台阶**，不空喊；不确定的晋升路径如实说"常见走向是…，因人而异"。
- **雇主类型适配**：若已知 `target_employer_type`，按 `employer-type-strategy.md` 排节奏与材料——
  冲国企技术岗/考编要盯提前批、备笔试、备齐学历/证书/政治面貌材料；冲民营工厂/中小私企可全年滚动投、主打对口证书 + 即战力。

## 模块 8：资源与下一步（专科口径，纯中性、不导流）
篇幅：250-400 字
数据来源：`references/resources-guide.md`（中性资源推荐方法）+ 搜索 0/5（对口证书、专升本资源）+ 模块 3/5/7 的结论

> 这是报告的收尾模块。它**回答"我现在具体可以用什么去落地前面的升学/就业建议"**——给的是用户能**自己上手**的
> 外部资源和行动指引，**不推销、不导流、不出现任何公司 / 老师 / 套餐 / 价格**。
> 写法标准见 `references/resources-guide.md`：具体、可获取、标时效、不编造、不打包票。

内容（从下面几类里**挑与这位用户最相关的 3-5 项**给，不要堆清单；**升学/就业两条腿都照顾到**）：
- **该考的对口证书 / 技能等级清单**：结合搜索 0 与专科口径，列出对这位用户最值得考的**具体职业资格证 /
  技能等级证（1+X）/ 行业证**（如电工、CAD/BIM、护士执业资格、会计等），说明对口性与优先级——这是专科求职最硬的敲门砖。
- **实操技能提升资源**：针对能力缺口给具体的学习/练手路径——公开课程平台、技能实训资源、行业技术社区、
  考证备考资料类型等；中性介绍、不带货。
- **（若升学可行）专升本备考资源**：本省官方信息渠道（省教育考试院）、公开备考资料/课程类型、对口本科院校信息怎么查。
  **只给"去哪查、有哪类资源"，不编造具体机构/班次/价格，也不暗示必须报班**（自学同样是正路）。
- **求职渠道与下一步**：适合专科技术岗/实习的招聘渠道、本地产业园/龙头雇主信息怎么持续跟进；
  **若已知 `target_employer_type`，按 `employer-type-strategy.md` 给对应渠道/备考资源**——国企技术岗/考编→官网/国资平台 +
  笔试备考资料；民营工厂/中小私企→BOSS/58/本地人才市场 + 对口考证资源。
  最后用一两句把"看完报告这周/这月先做哪一两件最关键的事"收口，与模块 7 呼应、不重复。

写作要点：
- **全部具体、可获取**：给得出名字/类型/方向的东西，不要泛泛"多考证多实践"。
- **中性、不带货**：可点名公开、广为人知的资源，但不吹捧、不引导购买、不暗示某资源/某机构最好。
- **标时效与甄别 + 绝不编造**：证书/政策/专升本类提醒"以官方最新信息为准"；拿不准是否真实存在的具体课程名/机构就不写。
- **诚实交代边界（一句话，非导流）**：给信心之前点明边界——报告帮你**看清升学还是就业、理清路径、给到能照着做的资源和动作**，
  但**替代不了你接下来实际的考证、备考、顶岗与投递；真正的进展来自你之后做的事**。这是诚实的预期管理，
  **不是导流尾巴**，落点在"接下来靠你自己推进"，不指向任何服务。
- **收尾自然、给信心**：用一句平实、鼓励但不浮夸的话结束（如"技术工种实操强反而吃香，按节奏走、证书攒起来，你有自己的优势"）。
  **绝不出现推销话术、联系方式、占位符、"本报告由 xx 生成"之类的机器尾巴或半成品痕迹。**
  （报告为干净中性排版，无品牌 logo；不强行编造任何联系方式或机构信息。）
