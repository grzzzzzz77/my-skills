# 求职深度分析与发展规划报告 — 模块结构模板（本科 + track）

报告标题格式：{school}{major}（{graduation_year}届）{target_city}求职分析与发展规划报告

> 本报告**直接面向求职者本人**，是一份纯分析与规划交付物，**不含任何推销 / 服务导流内容**。
> 以"资源与下一步"自然收尾（给可自己上手的外部资源），而非把读者导去任何付费服务。

共 **8 个模块**：1 画像 → 2 竞争力定位 → **3 求职路径与策略研判（核心）** → 4 目标市场 →
5 简历诊断 → 6 政策福利 → 7 行动建议与发展规划 → 8 资源与下一步。
（与专科 track 8 模块结构对称：专科第 3 模块是"升学 vs 就业研判"，本科第 3 模块是"求职路径研判"。）

> **按 degree 调口吻与重点（本 track 共用 8 模块结构，但口径随学历层次微调；v1 暂不另设 track）**：
> - **本科**：默认口径——应届校招主战场，看 GPA / 实习 / 项目 / 四六级 / 学生工作，模块照常。
> - **硕士**：仍是校招主战场，但**重点上移到"研究方向 / 课题 / 论文 / 专业纵深"与目标岗的对口度**；
>   **弱化"GPA、四六级、学生干部"这类本科生气的指标**；竞争力定位（模块 2）讲清研究方向能迁移到哪些岗、
>   有无高含金量实习；市场（模块 4）对标硕士起薪与对口岗，别套本科口径。**称呼可用"同学"**。
> - **博士**：主线不是"海投校招"，而是**研究方向与去向的匹配**——业界（研究院/算法科学家/研发专家）
>   vs 学界（高校教职/博后）。竞争力看**学术产出（论文 / 专利 / 顶会）与方向稀缺性**；
>   路径研判（模块 3）重点是"业界 vs 学界 + 博士专属渠道（人才引进 / 校招专项 / 教职招聘）"；
>   政策（模块 6）关注高层次人才引进 / 安家费类。不谈应届校招那套通用流程。
> 不确定 degree 细节（如硕士是学硕还是专硕、是否有业界实习）影响判断时，在确认关卡问一句。

## 报告开头：核心结论速览（写在模块 1 前，半页以内）

> 这是整份报告的"封面答案"——写在所有模块之前，让读者翻开第一眼就看到自己的处境和最该做的事，
> 不必读完 8 个模块才抓到重点。**它是后面各模块结论的浓缩，不引入任何新内容、更不编造。**

包含四小块，总计**半页以内、短而准**：
1. **一句话定位**：你现在处于什么处境（身份/阶段 + 竞争力大致水位 + 主攻方向）。
2. **3 条最关键发现**：从竞争力、市场、简历里挑出最该知道的 3 点（含 1 条优势、1-2 条短板）。
3. **本周就能做的 3 件事**：从行动建议里提炼最该立刻动手的 3 个具体小动作。
4. **方向一句话**：「主攻 X + 保底 Y」。

写作要点：
- **先写完后面 8 个模块，再回头把结论浓缩成这段**——它必须与正文一致，不得出现正文没有的判断。
- 重心随简历强弱走（与模块 5「重心自适应」一致）：强简历落"优势 + 提升点"，空/弱简历落"先去积累什么"。
- 只放结论与动作，不堆形容词、不打包票、不编造。

### 信息说明（紧跟速览，一行小字）

在速览下方用**一行小字**交代信息时效与来源，让读者知道数据有多新、该信谁：
- 写明本报告市场 / 政策 / 薪资数据的**采集时间**（如"数据采集于 2026 年 6 月"）与**主要来源类型**
  （公开招聘平台、地方官方政策文件等），并提示**具体数字以官方 / 平台最新信息为准**。
- 这是**中性的信息说明，不是机器味的免责尾巴**——只交代"数据多新、来源何处、以官方为准"，
  **不暴露工具名、不写"本报告由 xx 生成 / 仅供参考"之类的字样**。

## 模块 1：个人画像总览
篇幅：150-200 字
数据来源：用户简历

内容：
- 用一段话概括用户的核心背景：学校、专业、学历、毕业年份
- **明确点出用户的"身份 / 阶段"**（应届校招 / 在校找实习 / 已毕业 gap / 转专业转方向 / 考研保研并行等，见 `job_stage`）——这决定后面整条路径
- 列出简历中的关键亮点（如有实习经历/竞赛/项目，简要提及）
- 如果有明显缺失（如零实习），客观提及但不过度强调

写作要点：
- **开头先以称呼问候学生**（如"XX 同学，您好："），再用一句话点明"这是专门为你（学校·专业·届别·目标城市方向）整理的报告"——
  让学生一眼感到这是为他个人定制的，而非通用模板。学生姓名从简历提取；无名字时用"同学，您好"。
- 这是让用户确认"你看对了我的情况"的模块
- 保持客观陈述，不做价值判断
- 如果用户信息不完整，标注"以下分析基于您提供的信息，如有遗漏欢迎补充"

## 模块 2：竞争力定位
篇幅：400-550 字（本模块要写"实"，宁可多写也不要泛泛）
数据来源：school-tiers.md + 简历内容 + 搜索 0（专业对口方向，运行时搜索）+ 搜索 4（学校就业数据）

内容：
- 学历竞争力：用户学校在目标城市的梯队定位，HR 认知度如何
- 专业匹配度：用户专业与目标城市产业的契合程度
  - ⚠️ **跨专业 / 自学转方向的情况要专门处理**：若用户专业与目标岗不直接对口（如生物医学工程→AI、英语→产品），
    不要简单判"不匹配"，而要看其**是否已用项目/实习/作品完成迁移**——说清"专业非直接对口，但 XX 作品已对冲，
    且交叉背景可能是差异化"（差异化方向归模块 3/7）。
- **技能与项目资产盘点（核心，必须定式化、不能泛泛）**：把简历里的**具体技术栈和每段项目/实习**
  逐项对照目标岗（搜索 0 得到的核心技能要求），归成三类——
  - **直接命中**：与目标岗核心技能/经验直接吻合的，是"敲门砖"，简历应突出。
  - **强可迁移**：技术栈不完全一致、但能力可平移的（如独立交付力、数据库/接口经验、serverless/云函数≈后端逻辑），
    说清"它证明了什么、怎么往目标方向讲"。
  - **弱相关**：与目标岗重叠低的，点明应弱化（不是否定其价值，而是别占主篇幅；具体改法归到模块 5）。
- 应届生身份状态：是否在有效期内，对应什么权益（身份的"路径含义"在模块 3 展开）

写作要点：
- **核心是"资产盘点"那一段：必须点到简历里的具体技能名和具体项目名**，给出"对目标岗价值高/中/低 + 可迁移点"的判断，
  不要只说"经验丰富""项目扎实"这类空话。这是整份报告"懂行、为你定制"的体现。
- 与模块 5 分工：模块 2 做**价值定位**（你有哪些资产、值多少），模块 5 做**具体改法**（简历怎么改）；可相互指引但不重复。
- 使用 school-tiers.md 中的梯队描述，但不要暴露分档编号（不说"你属于 T3"）
- 如果学校不在知识库中，用通用描述，不编造
- 明确给出"在同类求职者中的大致定位"，如"中等偏上""具有竞争力但需要差异化"
- 若简历项目/技能信息太少不足以盘点，坦诚说明并就已有信息给方向性判断，不硬编造项目细节
- 不做绝对化判断

## 模块 3：求职路径与策略研判（本科核心，本科版"战略层"，决定后面所有模块的主线）
篇幅：350-550 字（本模块要写"实"，是把这位用户的处境讲透、给出主线的关键部分）
数据来源：简历 + 身份字段（`job_stage` / `graduation_year`）+ 搜索 0（方向）+ `employer-type-strategy.md` + 模块 2 竞争力结论

> 这一模块的立场（类比专科的"升学 vs 就业研判"）：**不替用户做人生决定，但基于客观条件，
> 替他把"该走哪条路、要不要两手准备"研判清楚**，常见落点是 **"主攻一条 + 保底一条"** 的组合，而非孤注一掷。

必须讲清以下三件事（按这位用户的实际情况，有的重、有的一句带过）：

**① 身份 / 阶段定位（先认清处境，它决定整条路径）**
- 先明确用户处在哪种阶段：在校应届找校招/正式工作、在校找实习（冲暑期实习转正）、已毕业 gap 找实习或工作、
  转专业/跨方向求职、考研保研并行、考公考编并行、二战等。
- **据实点出该身份的约束与机会**：如**已毕业 gap** 可能卡部分大厂"日常实习需在校生"的要求（更适合不卡身份的公司）；
  **跨专业**需用作品对冲非对口、扬长避短；**应届**要珍惜校招通道与应届政策窗口。不回避、不夸大。

**② 方向研判（若方向未定或多选）**
- 基于搜索 0 的对口方向 + 用户技能/兴趣的交集，在 2-3 个候选方向间研判该**主攻哪个**，给倾向性建议但不武断。
- 方向完全空白时，先收敛到 2-3 个候选方向并给各自的"匹配度 + 上手成本"判断，不硬替用户定死。
- 方向已明确时（如简历已锁定某岗），本条一句带过，把篇幅让给 ① 和 ③。

**③ 投递路径 / 赛道选择 + 两手准备**
- 结合**学历门槛、身份、雇主类型**（`employer-type-strategy.md`），研判该走哪条 / 哪几条路：
  大厂校招、创业/成长公司、国央企/考公考编、读研深造、出国等——说清各自的**窗口、门槛与代价**。
- 给出 **"主攻 X + 保底 Y"** 的组合建议（如"校招冲大厂 + 同步铺创业公司保底"、"求职为主 + 考公作两手"），
  让用户既有主线又有退路。

写作要点：
- 这是本科报告的**战略层**，类比专科模块 3。它**定调**，后面市场/简历/行动都顺着这条主线走。
- 必须结合客观事实（身份、学历门槛、市场竞争——接模块 2）给研判，不套通用话。
- 立场清晰但不武断：给**倾向性建议 + 两手准备**，尊重用户意愿（有人就是铁了心走某条路）。
- ⚠️ **身份据实**：gap / 转专业 / 二战 / 考公并行等非标准身份，要正视其约束与机会，不回避不夸大。
- 不制造焦虑、不做保证性承诺。

## 模块 4：目标市场分析
篇幅：300-400 字
数据来源：搜索 1（市场与薪资） + 搜索 3（产业动态）

内容：
- 目标城市该方向的岗位供需概况
- 薪资区间（标注数据来源和时间）
- 当前招聘市场节奏（校招/补录/社招的时间窗口）
- 头部雇主或行业方向简述

写作要点：
- 搜索到的数据要标注来源
- 如果搜索结果不充分，用"据公开招聘数据，该方向需求较为旺盛"兜底，不编造具体数字
- 既说机会也说竞争，不只呈现正面信息
- 如果用户未确定方向，对比 2-3 个推荐方向的市场情况（接模块 3 方向研判的结论；方法见 major-career-map.md）
- **求实习 / 非正式就业口径**：若用户目标是**实习**而非正式就业（见 `job_stage`），市场分析要**聚焦实习供需、日薪与转正机会**，
  薪资用**实习口径（日薪 / 月实习薪）**，不要直接套正式岗月薪数字当结论；正式岗薪资可作"转正后参考"附带一句。
- **雇主类型适配**：若已知 `target_employer_type`，结合 `employer-type-strategy.md` 点出该类型的**招聘节奏与笔面试形式**
  （如国央企提前批早、有笔试；大厂暑期实习→秋招、在线编程笔试；外企网测+群面）。未指定则就其最可能投的 2-3 类简述差异。

## 模块 5：简历诊断（健康度速览 + 深挖弱项 + 一条改写示范）
篇幅：550-750 字（强简历 / 空简历可酌减，见"重心自适应"）
数据来源：`resume-checklist.md`（7 维度池）+ 用户简历内容 + 搜索 0（目标岗 JD 要求）
+ `employer-type-strategy.md` + `resume-rewrite-craft.md`（改写范式与示范方法）

本模块**分三步写**，但**先按简历强弱定重心**：

> **重心自适应（重要）**：先看第一步速览的总体分布，再决定本模块的着力点——
> - **强简历（≥5 个 ✅）**：不要硬凑弱项。诊断转为"**优势如何讲到顶 + 1-2 个从优秀到顶尖的提升点**"，
>   并把更多篇幅让给模块 3（路径）与模块 7（投递策略）——强简历的瓶颈通常不在简历本身。
> - **空 / 弱简历（大半 ❌，几乎无实习/项目/技能可诊断）**：不要逐条列"你这也没有那也没有"。
>   点到关键缺口后，**重心转向"先去积累"**（补实习/项目/考证），把抓手让给模块 7 行动建议；改写示范选唯一能改的那条即可，不强求。
> - **中等简历（强弱掺杂）**：这是诊断模块的**主场**，正常三步深挖。

**第一步：简历健康度速览（一张小表 + 一句总评）**
- 按 `resume-checklist.md` 的 **7 个维度**，每维度给一个评级 **✅ 强 / ⚠️ 中 / ❌ 弱**，外加一句话结论，用 Markdown 表格呈现。
- 表格后**补一句总评定调**（避免单维评级误导）：如"整体底子很强，主要是细节打磨"或"简历内容偏空，当务之急是先去积累而非改写"。
  （⚠️ 注意：内容太少的简历，"真实性一致性"维度可能因"无内容可夸大"而显 ✅——别让它误导成"简历没问题"，靠总评定调。）

  | 维度 | 评级 | 一句话结论 |
  |---|---|---|
  | 定位与 JD 对齐 | ⚠️ 中 | 方向基本对，但缺目标岗 2 个 must-have 技能 |
  | 项目与实践质量 | ❌ 弱 | 项目只写职责无量化、无 GitHub |
  | …（其余维度）| … | … |

**第二步：深挖标 ❌/⚠️ 的 3-5 项**
- 只对评为弱/中的维度展开，每条给 **问题是什么 → 为什么影响求职 → 具体怎么改**，指向简历具体内容。
- "具体怎么改"按 `resume-rewrite-craft.md` 的范式给（STAR 落地结构、专业动词、加粗亮点），不要停在"建议优化"。
- 简历质量较好时，深挖部分转为"进一步优化建议"（指出亮点 + 怎么更好）。

**第三步：一条 before→after 改写示范**
- 挑这位用户简历里**最有代表性的一条弱经历**（实习/项目/校园其一），按 `resume-rewrite-craft.md` 的方法给示范：
  - 先贴 **原文：……**（用户简历里的真实原句）。
  - 再给 **建议改为：……**（套 STAR 落地模板、专业动词、`**加粗**`亮点）。
  - 末尾一句话说明**改了什么、为什么更好**。
- ⚠️ **真实性红线**：只基于用户已写的内容扩写/重组，**绝不虚构经历或数据**；
  缺的量化用占位提示让用户自己填，如"（补充具体数字：如 XX 件 / 提升 XX%）"，**绝不替他编数字**。
- 一份报告给 **1 条**示范即可（弱简历最多 2 条）；不要逐条改写整份简历——我们是诊断+教练，不是代写。
- 空简历几乎无内容可改时，此步可省，转而在模块 7 给"怎么先攒出能写的经历"。

写作要点：
- 速览给全貌、深挖给抓手；**绝不把 7 维度的所有条目都倒进报告**。
- 不要泛泛而谈（如"建议优化简历"），要指向具体内容（如"您的 XX 项目只描述了职责，建议补充量化成果"）。
- 语气建设性，"建议"而非"缺点"；信息不足以深诊时坦诚说明并给通用建议。
- **雇主类型适配**：若已知 `target_employer_type`，按 `employer-type-strategy.md` 调整诊断侧重——
  冲**国央企**额外看学历/四六级/党员/学生干部/获奖与排版规整；冲**互联网大厂**额外看项目深度/算法/GitHub；
  冲**外企**看有无英文版/STAR/leadership；冲**中小私企**看即战力与对口实操。未指定则按通用 + 其最可能投的类型提示。

## 模块 6：政策福利提醒
篇幅：200-300 字
数据来源：搜索 2（政策信息）+ hometown（户籍/生源地，影响适用性判断）

内容：
- 目标城市应届生可享受的补贴政策（金额、条件、有效期）
- 落户政策（如适用）
- 人才引进/紧缺人才相关政策（如适用）
- **适用性提醒**：明确指出哪些政策可能因户籍/生源地、社保缴纳、申领时限等条件而不适用，
  需要学生自行核对申领资格——不要让学生误以为一定能拿到

写作要点：
- 所有政策信息必须来自搜索结果，不从知识库中硬编码
- 标注"以上信息来源于公开政策文件，具体以官方最新公告为准"
- **求实习 / 在校阶段口径**：若用户目标是**实习**或仍在校（见 `job_stage`），应届**就业类补贴通常不适用**
  （多要求正式就业 + 缴社保）——**据实说明、别让用户误以为实习能领**；可点出"毕业窗口期内若后续正式就业再适用"，并给官方渠道。
- **不替学生下"你符合申领条件"的结论**：政策列出来 + 提示适用条件 + 让其自行核验
  - 已知 hometown 且与目标城市不同 → 区分说明"本地生源 / 外地生源各自适用什么"
  - 未知 hometown → 只做通用提醒，注明"是否适用取决于户籍/生源地等条件，请自行核验"
- 如果搜索不到具体政策，提供官方查询渠道（如当地人社局官网）
- 提醒用户核验政策有效期

## 模块 7：行动建议与发展规划（短期落地 + 中长期路径）
篇幅：400-550 字（本模块要写"实"——既有马上能做的，也有几年的成长地图）
数据来源：综合以上所有模块的分析（尤其模块 3 的路径研判结论）+ 搜索 0（目标方向技能要求）+ 搜索 1（市场节奏）

本模块分**两层**写，前者解决"现在怎么动"，后者解决"往哪儿长"，**都顺着模块 3 定的主线走**：

**A. 短期落地（按时间维度，具体可执行）**
- 基于用户当前状态（job_status）与模块 3 的路径主线，按 **本周 → 本月 → 未来 1-3 个月** 给分阶段行动。
- 包含：简历优化方向（接模块 5 诊断）、技能补强重点（接搜索 0 的目标岗要求）、
  投递渠道与节奏（接模块 4 市场分析）、面试准备重点。
- **空 / 弱简历**：本模块要承接模块 5 让出的重心——给"怎么先攒出能写的经历"（去哪找实习、做什么项目、考什么证）的具体起步动作。
- 给出 **Plan B**：主路径受阻时的备选（呼应模块 3 的"两手准备"）。

**B. 中长期发展规划（1-3 年成长路径）**
- 勾勒这位用户在目标方向上**未来 1-3 年的能力台阶**：从应届/入门 → 进阶大致要补齐哪些能力、
  攒哪些经验、达到什么水平（结合搜索 0 得到的"进阶技能"维度，不空喊）。
- 点出方向可能的**分化或演进**（如后端→架构/中间件、或转管理/转方向的常见路径），让用户对"几年后往哪走"有预期。
- 与短期衔接：说清现在打的基础如何服务于中长期目标，避免只顾眼前投递、忽视成长方向。

写作要点：
- 短期建议必须具体可执行，不要"加油努力"式空话；中长期规划要落到**能力/经验/水平**，不要只画大饼。

- 本模块给"做什么、往哪长"；**具体用什么资源去做，留到模块 8（资源与下一步）**，两者分工不重复。
- **雇主类型适配**：若已知 `target_employer_type`，按 `employer-type-strategy.md` 排该类型的**投递节奏与要准备的材料**——
  冲国央企要赶提前批、备笔试（行测/公基/专业课）、备齐四六级/党员材料；冲大厂要抓暑期实习、刷题、整理 GitHub；
  冲外企要早做英文简历 + 在线测评 + 群面练习；冲中小私企可全年滚动投、主打即战力。未指定则给 2-3 类的节奏对比。

## 模块 8：资源与下一步（替代原"服务承接"模块，纯中性、不导流）
篇幅：250-400 字
数据来源：`references/resources-guide.md`（中性资源推荐方法）+ 搜索 0（目标岗技能/证书）+ 模块 5/7 的结论

> 这是报告的收尾模块。它**回答"我现在具体可以用什么去落地前面的建议"**——给的是用户能**自己上手**的
> 外部资源和行动指引，**不推销、不导流、不出现任何公司 / 老师 / 套餐 / 价格**。
> 写法标准见 `references/resources-guide.md`，核心是：具体、可获取、标时效、不编造、不打包票。

内容（从下面几类里**挑与这位用户最相关的 3-5 项**给，不要面面俱到堆清单）：
- **该补的能力 / 证书清单**：结合搜索 0 得到的目标岗要求，列出对这位用户最值得补的**具体技能点或证书**
  （如某门语言/框架、某项资格证），说明为什么对口、优先级如何。
- **学习与提升资源**：针对上面的能力缺口，给**具体的学习路径或资源类型**——可点名公开课程平台、
  权威文档/书、技术社区、开源项目、练习平台等。免费付费都可推荐，但**只做中性介绍、不替任何一家背书带货**。
- **求职渠道与信息源**：适合这位用户方向的招聘渠道、行业信息源、对标可参考的岗位 JD 在哪看，方便其自己持续跟进。
  **若已知 `target_employer_type`，按 `employer-type-strategy.md` 给对应渠道与备考资源类型**——国央企→官网/国资校招平台 +
  行测/公基备考资料；大厂→牛客/BOSS+内推 + 刷题平台；外企→LinkedIn+校招 + 英文简历/网测练习；中小私企→BOSS/58+本地招聘。

写作要点：
- **全部具体、可获取**：不要泛泛说"多学习多实践"，要给得出名字/类型/方向的东西（接 `resources-guide.md` 的标准）。
- **中性、不带货**：可以点名公开、广为人知的资源，但不吹捧、不引导购买、不暗示某资源最好；同类资源给 1-2 个示例即可。
- **标时效与甄别**：课程/证书/政策类资源提醒"以官方最新信息为准、注意辨别质量"，不为任何资源的效果打包票。

- **诚实交代边界（一句话，非导流）**：在给信心之前，用一句平实的话点明这份报告的边界——
  它帮你**看清处境、理清路径、给到能照着做的资源和动作**，但**替代不了你接下来实际的投递、练习与打磨；
  真正的进展来自你之后做的事**。这是诚实的预期管理，**不是"我们能帮你更多"那种导流尾巴**，
  落点在"接下来靠你自己推进"，不指向任何服务。
- **收尾自然、给信心**：用一句平实、鼓励但不浮夸的话结束整份报告（如"方向清楚、按节奏推进，你是有竞争力的"）。
  **绝不出现推销话术、联系方式、占位符、"本报告由 xx 生成"之类的机器尾巴或半成品痕迹。**
  （报告为干净中性排版，无品牌 logo；不强行编造任何联系方式或机构信息。）
