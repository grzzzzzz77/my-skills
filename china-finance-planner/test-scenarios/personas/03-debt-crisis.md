# 人设 03：以贷养贷的网贷危机

## 背景
- 王浩 27 岁，成都，销售工作，月收入不稳定（到手 6,000–11,000，平均 8,000）
- 单身，租房 1,500/月
- 起因：两年前创业失败欠了 8 万，开始拆东墙补西墙

## 债务全景（用户一开始只说"欠了几万"，追问后才全盘托出）
- 信用卡 A：欠 32,000，只还最低还款（循环利息 ~18%）
- 信用卡 B：分期 18,000（12 期，月费率 0.75% → 实际年化 ~16%）
- 借呗：45,000，年化 14.6%
- 某网贷：28,000，年化 23.9%
- 京东白条：6,000
- 欠表哥：20,000（无息，没敢说实话）
- **合计约 14.9 万，月供合计约 9,200 > 平均月收入 8,000**

## 资产
存款 3,000；无其他

## 其他
- 已有一个网贷逾期 5 天（开始收到催收电话）
- 不知道哪些上征信（都上）
- 考虑过"再借一笔大的把小的都还了"（典型以贷养贷思维）
- 在网上看到"债务优化公司，收费 5,000 帮你搞定"（二次收割预警）

## 预期覆盖点
- [ ] 触发危机协议：停止新增借贷、全面盘点、不评判的语气
- [ ] 月供 > 收入识别为危机状态
- [ ] 债务排序：网贷 23.9% 最先；逾期优先处理
- [ ] 信用卡个性化分期（停息挂账）协商指引（引述监管办法第 70 条）
- [ ] 明确劝阻"债务优化公司"（诈骗/二次收割）
- [ ] 暴力催收应对与 12348/12378 渠道
- [ ] 生存预算 + 清偿时间表（按收入 8,000、还款能力约 4,500/月推演）
- [ ] 不做长期规划 —— 先上岸
- [ ] 征信教育：5 年规则、不能花钱洗白
