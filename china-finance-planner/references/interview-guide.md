# 访谈指南

开始或继续与新用户的访谈时读这个文件。

## 访谈原则

- 一次问 2-3 个问题。绝不甩一堵问题墙。
- 每个回答先温暖地接住，再问下一个。
- 问题不直观时解释为什么问（"问你所在城市，是因为社保基数、房租扣除额度、
  公积金政策都跟着城市走"）。
- 用户上传单据时静默提取财务数据，不要解说你在忽略什么。
- 每轮结束保存进度到 `1-my-profile.md`。
- 用户说"不知道"—— 帮他推算，或标注为估算值。
- 每轮结束用 2-3 句自然的话复述确认："我理解得对吗？""有漏的吗？"保持温度，
  别像机器人。例："所以你和你爱人在杭州，孩子 3 岁刚上幼儿园，你在互联网公司，
  爱人是小学老师。对吧？"
- 每个数字默默做合理性检查。支出大于收入、利率异常、时间线矛盾 —— 随口问一句。
- 第 3 轮起与前几轮交叉印证。数字应该讲得出同一个故事。对不上就澄清，别假设。

## 建议用户准备的材料

访谈早期提一句（但别变成作业 —— 随时可以传）：

- 个税 App 截图（收入纳税明细、专项附加扣除填报情况）
- 工资条或银行流水（近 2-3 个月）
- 社保/公积金缴存明细（支付宝/微信城市服务可查）
- 房贷合同或还款计划表
- 基金/股票/理财账户持仓截图
- 外币资产证明（外币存款、港股/美股账户截图）
- 虚拟币持仓截图（交易所资产页或钱包余额 —— 提醒遮住账号信息）
- 商业保险保单
- 各类贷款/欠款合同

用户给不了或不想找，就用现有的信息做，标注哪些是估算、哪些是确认值。

## 第 1 轮：你是谁？（生活背景）

这一轮塑造一切 —— 税、福利、保险、传承。

**问题：**
- 称呼和年龄（有伴侣的话伴侣年龄）
- 所在城市（精确到市 —— 社保基数、房租扣除、公积金政策都按城市走）
- 婚姻状况：单身 / 已婚 / 同居 / 离异 / 丧偶
  - 有伴侣：是否初婚？（重组家庭影响传承规划）
- 孩子：几个、几岁？
  - 有没有需要长期照护的情况？
  - 有没有前段关系的孩子？（抚养费义务）
  - 成年子女仍在读书或需要支持？
- 是否在经济上支持父母？父母年龄、有没有退休金和医保？
- 住房：自有（有贷/无贷）、租房、住父母家、单位宿舍？
- 工作形态：全职 / 兼职 / 合同工 / 自由职业 / 个体户 / 灵活就业 / 待业 / 退休 / 学生
  - 行业和大致职业
  - 收入稳定性：稳定、波动、极不稳定？
- 单位福利：五险一金按什么基数缴？有没有补充医疗、企业年金、住房补贴？
- 户籍与社保缴纳地一致吗？（影响医保使用和购房资格）
- 有没有境外身份/永居？有没有在境外长期居住的计划？
- 健康状况：有没有影响财务规划的情况？（影响保险可保性）
- 目前在享受什么政策待遇？（失业金、低保、灵活就业社保补贴等）

**为什么问这些：**
- 城市 → 社保基数、房租扣除档位、公积金政策、房价语境
- 婚姻 → 扣除分配、财产制度、传承安排
- 孩子 → 子女教育扣除、教育金、监护安排
- 父母 → 赡养老人扣除、医疗储备、长期照护风险
- 工作形态 → 社保怎么缴、收入稳定性、税务处理
- 境外身份 → 税收居民身份、CRS、跨境申报

**进入下一轮前：**
- 用 2-3 句话复述他的生活状况，确认。
- 检查：工作形态和收入稳定性描述一致吗？
- 存入 1-my-profile.md。

## 第 2 轮：你赚多少？（全部收入来源）

**工资薪金：**
- 税前月薪/年薪
- 税后到手（月工资或年包）
- 年终奖多少、怎么发（单独计税还是并入？）
- 公积金/社保按什么基数缴（问到手工资反推验证）
- 伴侣收入（同样拆解）

**经营/副业：**
- 个体户/自由职业/自媒体/电商：营收、成本、净利润
- 有没有注册主体？开票吗？

**投资与财产收入：**
- 房租收入（租金、成本）
- 股息、利息、理财收益
- 境外收入（外币工资、境外房租、美股股息）
- 虚拟币相关收益（如有，只记录事实，见 crypto-assets.md）

**转移性收入：**
- 父母资助、赡养费、抚养费
- 失业金、各类补贴

**其他：**
- 收入未来 1-3 年的预期（涨薪、跳槽、转行、生娃停工）

**验证：** 税前税后差距和社保基数匹配吗？年终奖有没有提到？
存入 1-my-profile.md。

## 第 3 轮：你花多少？（支出）

引导用户按类别回忆，用支付 App 年度账单辅助（支付宝/微信都有年度账单）：

- 住房：房贷月供 / 房租、物业、水电煤
- 吃：买菜做饭、外食、咖啡奶茶
- 行：通勤、车贷、油费/充电、打车
- 孩子：学费、培训、托管、奶粉尿布
- 父母：赡养费、医疗费
- 保险：商业保险年缴保费（平摊到月）
- 通讯/订阅：话费、视频会员、各类 App 订阅
- 购物：衣服、数码、家居
- 社交人情：聚餐、红包、随礼（中国语境下这可能是大头，别漏）
- 医疗：日常看病、药品
- 娱乐/旅行/爱好
- 养宠
- 其他固定支出

**方法提示：** 让用户翻一下支付宝/微信/银行 App 的月度账单比纯回忆准得多。
"你打开支付宝 — 我的 — 账单，看看上个月总支出是多少？"

**验证：** 合计 < 税后收入？如果不是，缺口从哪来？支出结构和第 1 轮的生活
状况自洽吗（有孩子却没有孩子支出？）？存入 1-my-profile.md。

## 第 4 轮：你欠多少？（负债）

- 房贷：余额、利率（商贷/公积金/组合贷）、剩余年限、月供、重定价日
- 车贷/消费贷：余额、利率、月供
- 信用卡：总欠款、是否只还最低还款、分期情况（问清分期手续费率）
- 花呗/借呗/白条/微粒贷等：余额、利率
- 网贷：平台、余额、实际年化利率
- 私人借款：欠亲友的、欠别人的
- 担保：有没有给别人做担保？（隐性负债，常被忽略）

**每个都要问：余额、利率、月供、剩余期限。**

**验证：** 利率在正常区间吗？（房贷 2.6–4.5%、车贷 3–8%、信用卡分期实际
13–18%、网贷 7–24%）月供之和与第 3 轮支出里的还贷项对得上吗？
有没有以贷养贷的迹象（多平台小额、只还最低）？有 → 标记危机处理路径。
存入 1-my-profile.md。

## 第 5 轮：你有什么？（资产 —— 含外币与虚拟币）

**人民币资产：**
- 活期/定期存款（分银行问 —— 单家银行超 50 万要提示存款保险上限）
- 货币基金/余额宝类
- 银行理财（风险等级、期限）
- 国债、大额存单
- 基金（场外/ETF，大致持仓与成本）
- 股票（A 股，市值与成本）
- 个人养老金账户（余额、买了什么产品）
- 公积金账户余额
- 保险现金价值（年金/增额寿的现金价值）

**外币资产：**
- 外币存款（币种、金额、在哪个银行/地区）
- 港股/美股（通过什么渠道：港股通/QDII/境外券商，市值与成本）
- 境外房产或其他资产
- 境外退休金/年金

**虚拟币持仓：**
- 币种（BTC/ETH/USDT/其他）、数量、放在哪（交易所/自托管钱包 —— 不问具体平台名
  也可以，只记类别）
- 大致成本（买入均价或总投入）
- 是否加杠杆/合约（风险预警用）
- 获取方式：早年买入/挖矿/他人转账（影响后续处理的复杂度）

**实物与其他：**
- 房产（自住房估值、投资房估值与租金）
- 车（估值）
- 其他值钱资产（黄金、收藏品）

**每项记录：原币金额、币种、当前估值、估值日期。** 估值不确定就标估算。

**验证：** 投资类收入（第 2 轮）和资产规模匹配吗？有没有说了炒股却没有股票
资产？存入 1-my-profile.md。

## 第 6 轮：你保什么？（保障）

- 社保：五险都在缴吗？什么基数？断缴过吗？
- 医保：职工医保还是居民医保？有没有惠民保？
- 商业保险（逐份问：险种、保额、年缴保费、缴费期、保障期、被保险人）：
  - 百万医疗险
  - 重疾险
  - 定期寿险
  - 意外险
  - 年金/增额终身寿（兼具储蓄属性，记入资产也要记入保费支出）
- 单位团险：补充医疗、团体定寿、团体重疾
- 家里的经济支柱是谁？TA 出事了家庭现金流能撑多久？

**验证：** 经济支柱的定寿/重疾保额和收入、房贷、孩子年龄匹配吗？
（粗算：定寿保额 ≈ 房贷余额 + 孩子到独立的生活教育费 + 父母赡养费 - 现有存款）
存入 1-my-profile.md。

---

## 第 7 轮：你要什么？（目标）

- 短期（1 年内）：比如存下 X 万、还清某笔债、旅行
- 中期（1-5 年）：买房/换房、生娃、创业、留学
- 长期（5 年以上）：孩子教育金、多少岁退休、退休后的生活标准
- 每个目标问：大概需要多少钱？有没有开始准备？
- 优先级：如果只能先做一个，是哪个？
- 财务上最焦虑的一件事是什么？（往往比目标本身更重要）

**验证：** 目标和收入/资产现实吗？不现实不打击 —— 记下来，在建计划时用数字说话。
存入 1-my-profile.md，标记访谈完成。
