# 计算规范与仪表盘

建计划、做推演、生成仪表盘时读这个文件。

## 计算总则

1. **一切金额计算用代码或逐步演算完成，绝不心算拍脑袋。** 关键数字保留计算过程。
2. 所有汇总以人民币为本位币；原币明细永远保留。
3. 每个推演标注假设（收益率、通胀率、汇率），并给乐观/中性/保守三档。
4. 算完做一致性检查（SKILL.md 第 5 步），不过就修。

## 核心计算

### 1. 预算分析

- 月度结余 = 月均税后收入 - 月均总支出
- 储蓄率 = 月度结余 ÷ 月均税后收入
- 参考线：储蓄率 <10% 偏紧、10–20% 健康、20–40% 优秀、>40% 极佳（或收入高/支出漏记）
- 支出分类占比 vs 参考区间（中国城镇家庭大致语境）：
  - 住房（含房贷/房租）：25–40%（一线城市可能 40%+，单独提示）
  - 吃：15–25%；行：5–10%；孩子：10–25%（有娃家庭）
  - 人情社交：3–10%；保险：5–15%；娱乐旅行：5–10%
- 识别"拿铁因子"：高频小额支出年化（每天 30 元咖啡 = 10,950/年）

### 2. 个税测算

- 年应纳税所得额 = 年综合收入 - 60,000 - 专项扣除（三险一金个人部分）
  - 专项附加扣除 - 个人养老金（≤12,000）- 其他扣除
- 查七级税率表（current-figures.md）算税额
- 年终奖：单独计税 vs 并入综合所得，两种都算，取低
- 提示未填的专项附加扣除（对照访谈信息逐项检查）：
  有 3 岁以下孩子？有学龄孩子？父母满 60？有房贷/房租？在考证/读研？
  去年大病自付超 1.5 万？个人养老金存了没？

### 3. 债务清偿

- 每笔债务列：余额、利率、月供、剩余期限
- 排序策略：
  - **雪崩法**（先灭利率最高的）—— 数学最优，默认推荐
  - **雪球法**（先灭余额最小的）—— 心理激励强，债务笔数多且用户意志力弱时用
- 清偿推演：按当前月供 vs 每月多还 X 元，对比总利息和清零时间
- 信用卡分期/网贷：把"手续费率"换算成实际年化（IRR 口径）再排序
- 警示线：月供占税后收入 >50% = 高危；>40% = 紧张

### 4. 应急金

- 目标 = 月刚性支出 × 月数：
  - 收入稳定（体制内/大型企业）：3–6 个月
  - 收入波动（销售/自由职业）：6–12 个月
  - 有孩子/有房贷/单收入家庭：取上限
- 刚性支出 = 住房 + 吃饭 + 交通 + 保险 + 债务月供 + 孩子必需 + 父母必需
- 存放建议：货币基金、银行 T+0 理财、短期存款 —— 流动性优先，不谈收益

### 5. 退休推演

- 步骤：
  1. 估算退休后年支出（当前支出的 70–80%，按通胀折到退休年）
  2. 估算社保养老金（用 current-figures.md 的公式粗算，标注"估算"）
  3. 缺口 = 退休年支出 - 社保养老金 - 其他确定收入（房租、年金）
  4. 需要的个人储备 = 缺口 × 退休年数（或用 4% 法则：缺口 × 25）
  5. 反推每月需储蓄/投资金额（按假设收益率）
- 三档情景：保守（年化 3%）、中性（4.5%）、乐观（6%）
- 延迟退休影响：按用户的出生年月算法定退休年龄（见 retirement-income.md 速查表）

### 6. 教育金

- 按目标学校类型估总费用（公立大学约 10–15 万总费用；私立/留学另算，
  留学本科英美约 150–250 万，需联网核实当年数据）
- 反推每月定投额（假设年化 4–5%，教育金投资期限长可略积极，临近使用转保守）

### 7. 净资产

- 总资产 = 现金存款 + 投资（理财/基金/股票按当前估值）+ 公积金 + 个人养老金
  + 保险现金价值 + 房产估值 + 车估值（可选项，注明快速贬值）+ 外币资产折人民币
  + 虚拟币持仓估值（单独列示）
- 总负债 = 房贷余额 + 车贷 + 消费贷 + 信用卡欠款 + 网贷 + 私人借款
- **净资产（含虚拟币）** 与 **净资产（防御口径，不含虚拟币）** 两个数字都给
- 房产估值标"估算"，可用小区近期挂牌价打 9 折粗估

## 多币种处理规范

1. **记录格式**：每项外币资产记录 `原币金额 | 币种 | 汇率 | 汇率日期 | 汇率来源 |
   折人民币`。
2. **汇率获取**：使用前联网查当日中间价或银行牌价，标注来源（中国外汇交易中心/
   银行牌价页面）与时间。同一份报告用同一组汇率。
3. **常见币种**：USD、HKD、EUR、JPY、GBP。港币资产注意港币盯住美元
   （7.75–7.85 联系汇率区间）。
4. **汇率风险提示**：外币资产占比 >20% 时，在计划里加一节汇率情景
   （人民币 ±5% 对净资产的影响）。
5. **汇兑成本**：提醒银行现汇买入/卖出价差、跨境汇款手续费和电报费。

## 虚拟币估值规范

1. 估值来源：公开行情聚合网站，标注来源与时间戳（如"CoinGecko，2026-09-16
   22:00 UTC+8"）。
2. 折算路径：币种 → USD（或 USDT）→ CNY，使用与外币资产同一组汇率。
3. 成本记录：用户提供的总投入/均价，标注"用户自述"。
4. 展示：虚拟币在仪表盘独立卡片展示，不计入"投资资产"分类汇总，注明
   "波动极大，估值仅供参考"。
5. 合规与风险口径：见 `references/crypto-assets.md`。

## 仪表盘规范（4-my-dashboard.html）

单文件自包含 HTML，Chart.js 从 CDN 加载（加 CDN 失败时的文字降级提示）。
中文界面，配色克制专业（深色标题 + 白底 + 一套主色），移动端可读。

### 板块清单

1. **页头**：用户名、生成日期、数据截止日期、一句话财务体检结论
2. **KPI 卡片**：月税后收入、月总支出、月结余、储蓄率、净资产（含/不含虚拟币
   两个口径）、总负债、应急金月数
3. **财务健康检查**：红黄绿列表（应急金够不够、债务收入比、保险缺口、
   专项附加扣除漏项、单家银行存款超 50 万、外币集中度）
4. **支出环形图**：分类占比
5. **收入 vs 支出柱状图**：近 N 个月（有数据的话）
6. **建议预算表**：当前 vs 建议，差额标红/绿
7. **债务清偿时间线**：各债务清零时间 + 总利息对比（当前 vs 优化后）
8. **净资产推演**：10/20/30 年，三档情景
9. **应急金进度条**：当前 vs 目标
10. **退休推演**：三情景切换标签页，社保养老金 vs 缺口 vs 储备目标
11. **教育金追踪**（有孩子时）：目标 vs 当前进度
12. **分阶段月度资金分配**：应急金期 → 还债期 → 投资期，各阶段每月钱往哪去
13. **漏拿的福利/扣除清单**：未填专项附加扣除、未开个人养老金、未领补贴，
    每项标注"每年约多拿 X 元"
14. **养老金三支柱水位**：社保（估算）/ 企业年金 / 个人养老金
15. **税务日历**：汇算 3.1–6.30、专项附加扣除确认 12 月、个人养老金缴存截止
    12.31、房贷重定价日
16. **行动清单**：按优先级排序，每条带"为什么"和预期效果
17. **投资增长对比**：月投 X 元在 存款/国债/宽基指数 三档假设下的 10/20/30 年
    增长曲线（标注假设，联网核实过的费率）
18. **资产币种构成图**：人民币/美元/港币/其他/虚拟币 占比
19. **虚拟币持仓卡片**（如持有）：币种、数量、估值、成本、盈亏、估值时间与来源、
    风险提示
20. **核心洞察**：3–5 条最重要的发现，每条一句话 + 一个数字

### 技术要求

- 数字格式化：千分位、人民币用 ¥，外币标注币种符号与原币金额
- 所有图表数字必须与 2-my-budget.md、3-my-plan.md 完全一致
- 页脚：免责声明（非投资建议）+ 数据文件导航（列出配套文件名与用途）
