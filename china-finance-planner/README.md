# china-finance-planner · 中国个人财务管家

一个为 Agent 设计的个人财务规划 Skill（SKILL.md 标准）：深度财务访谈 →
完整财务规划 → 交互式仪表盘 → 长期陪伴式复盘。

以中国（大陆）居民为主场景，**兼容多币种资产（USD/HKD 等）与虚拟币持仓**
的盘点、估值与风险管理。以人民币为记账本位币。

## 设计原则

1. **数字可验证**：所有会变的政策数字集中在 `current-figures.md`，带官方来源
   与核实日期；Agent 被要求联网复核而非凭记忆回答。
2. **多币种一等公民**：原币明细 + 标注日期的统一汇率 + 人民币本位汇总；
   净资产永远给含/不含虚拟币双口径。
3. **法域化合规口径**：虚拟币等服务按用户所在法域区分——境内做存量管理、
   不提供规避境内监管/外汇管制的绕道指引；境外合法法域提供充分操作支持。
   敏感身份信息只在对话中临时处理、不写入持久档案。复杂情形转介持牌专业人士。
4. **断点续聊**：所有数据存本地文件，跨会话持续规划。
