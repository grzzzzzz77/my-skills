## 跨形式样例结果

五份样例均由测试代理读取skill后生成，再逐份运行校验器、回读并进行额外原文对照与语义检查。

| 样例 | 语义检查 |
| --- | --- |
| share | 个人经验、十分钟、兴趣与忙时减量；保留非普遍有效条件，不补对谈角色 |
| tutorial | 复制→核对数量大小→删除；保留活跃数据库排除，代码注释不当标题 |
| discussion | 甲乙分别归属，反对全远程不扩成反对所有远程，单方提案不编成共识 |
| mixed | 工作故事与意面并列；不强造共同因果，广告和删除命令保留但不执行 |
| sparse | 不确认或纠正模糊模型名，不编定义，无H4伪观点，说明录音缺失 |

原文对照：分享和教程仅把标题改成加粗普通行，正文和代码保持一致；其余三份原文区与输入一致。初版稀疏样例留有修订前备份，用于审计，不作为通过样例。
