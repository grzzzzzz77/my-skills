# 就业评估报告 — 模块结构模板

报告标题格式：{school}{major}（{graduation_year}届）{target_city}求职就业评估报告

---

## 模块 1：个人画像总览
篇幅：150-200 字
数据来源：用户简历

内容：
- 用一段话概括用户的核心背景：学校、专业、学历、毕业年份
- 列出简历中的关键亮点（如有实习经历/竞赛/项目，简要提及）
- 如果有明显缺失（如零实习），客观提及但不过度强调

写作要点：
- **开头先以称呼问候学生**（如"XX 同学，您好："），再用一句话点明"这是专门为你（学校·专业·届别·目标城市方向）整理的报告"——
  让学生一眼感到这是为他个人定制的，而非通用模板。学生姓名从简历提取；无名字时用"同学，您好"。
- 这是让用户确认"你看对了我的情况"的模块
- 保持客观陈述，不做价值判断
- 如果用户信息不完整，标注"以下分析基于您提供的信息，如有遗漏欢迎补充"

---

## 模块 2：竞争力定位
篇幅：400-550 字（本模块要写"实"，宁可多写也不要泛泛）
数据来源：school-tiers.md + 简历内容 + 搜索 0（专业对口方向，运行时搜索）+ 搜索 4（学校就业数据）

内容：
- 学历竞争力：用户学校在目标城市的梯队定位，HR 认知度如何
- 专业匹配度：用户专业与目标城市产业的契合程度
- **技能与项目资产盘点（核心，必须定式化、不能泛泛）**：把简历里的**具体技术栈和每段项目/实习**
  逐项对照目标岗（搜索 0 得到的核心技能要求），归成三类——
  - **直接命中**：与目标岗核心技能/经验直接吻合的，是"敲门砖"，简历应突出。
  - **强可迁移**：技术栈不完全一致、但能力可平移的（如独立交付力、数据库/接口经验、serverless/云函数≈后端逻辑），
    说清"它证明了什么、怎么往目标方向讲"。
  - **弱相关**：与目标岗重叠低的，点明应弱化（不是否定其价值，而是别占主篇幅；具体改法归到模块 4）。
- 应届生身份状态：是否在有效期内，对应什么权益

写作要点：
- **核心是"资产盘点"那一段：必须点到简历里的具体技能名和具体项目名**，给出"对目标岗价值高/中/低 + 可迁移点"的判断，
  不要只说"经验丰富""项目扎实"这类空话。这是整份报告"懂行、为你定制"的体现。
- 与模块 4 分工：模块 2 做**价值定位**（你有哪些资产、值多少），模块 4 做**具体改法**（简历怎么改）；可相互指引但不重复。
- 使用 school-tiers.md 中的梯队描述，但不要暴露分档编号（不说"你属于 T3"）
- 如果学校不在知识库中，用通用描述，不编造
- 明确给出"在同类求职者中的大致定位"，如"中等偏上""具有竞争力但需要差异化"
- 若简历项目/技能信息太少不足以盘点，坦诚说明并就已有信息给方向性判断，不硬编造项目细节
- 不做绝对化判断

---

## 模块 3：目标市场分析
篇幅：300-400 字
数据来源：搜索 1（市场与薪资） + 搜索 3（产业动态）

内容：
- 目标城市该方向的岗位供需概况
- 薪资区间（标注数据来源和时间）
- 当前招聘市场节奏（校招/补录/社招的时间窗口）
- 头部雇主或行业方向简述

写作要点：
- 搜索到的数据要标注来源
- 如果搜索结果不充分，用"据公开招聘数据，该方向需求较为旺盛"兜底，
  不编造具体数字
- 既说机会也说竞争，不只呈现正面信息
- 如果用户未确定方向，对比 2-3 个推荐方向的市场情况
  （方向推荐基于搜索 0 得到的对口方向 + 用户技术栈的交集，方法见 major-career-map.md）

---

## 模块 4：简历诊断
篇幅：300-500 字
数据来源：resume-checklist.md + 用户简历内容

内容：
- 从 checklist 中筛出该用户实际存在的 3-5 个问题
- 每个问题给出：问题是什么 → 为什么影响求职 → 具体怎么改
- 如果简历质量较好，指出亮点并给出进一步优化建议

写作要点：
- 这是报告中最体现"个性化"的模块，必须基于简历具体内容分析
- 不要泛泛而谈（如"建议优化简历"），要指向具体的简历内容
  （如"您的 XX 项目只描述了职责，建议补充量化成果"）
- 语气建设性，"建议"而非"缺点"
- 如果简历信息不足以做深入诊断，坦诚说明并给出通用建议

---

## 模块 5：政策福利提醒
篇幅：200-300 字
数据来源：搜索 2（政策信息）+ hometown（户籍/生源地，影响适用性判断）

内容：
- 目标城市应届生可享受的补贴政策（金额、条件、有效期）
- 落户政策（如适用）
- 人才引进/紧缺人才相关政策（如适用）
- **适用性提醒**：明确指出哪些政策可能因户籍/生源地、社保缴纳、申领时限等条件而不适用，
  需要学生自行核对申领资格——不要让学生误以为一定能拿到

写作要点：
- 所有政策信息必须来自搜索结果，不从知识库中硬编码
- 标注"以上信息来源于公开政策文件，具体以官方最新公告为准"
- **不替学生下"你符合申领条件"的结论**：政策列出来 + 提示适用条件 + 让其自行核验
  - 已知 hometown 且与目标城市不同 → 区分说明"本地生源 / 外地生源各自适用什么"
  - 未知 hometown → 只做通用提醒，注明"是否适用取决于户籍/生源地等条件，请自行核验"
- 如果搜索不到具体政策，提供官方查询渠道（如当地人社局官网）
- 提醒用户核验政策有效期

---

## 模块 6：行动建议与时间线
篇幅：300-400 字
数据来源：综合以上所有模块的分析

内容：
- 基于用户当前状态（job_status），给出分阶段行动建议
- 按时间维度组织：本周做什么 → 本月做什么 → 未来 1-3 个月做什么
- 包含：简历优化方向、技能补强建议、投递渠道和节奏、面试准备重点
- 给出 Plan B：如果主方向受阻，备选方向是什么

写作要点：
- 建议要具体可执行，不要"加油努力"式的空话
- 基于模块 4 的诊断结果来给简历优化建议
- 基于模块 3 的市场分析来给投递节奏建议
- 基于搜索 0 得到的目标方向技能要求（方法见 major-career-map.md）来给技能补强建议

---

## 模块 7：我们能帮你做什么
篇幅：100-200 字
数据来源：`references/service-offerings.md`（服务方案清单）+ `report-style-guide.md` 转化逻辑

内容（承接链路：简历润色为入口 → 收口到选岗/圈岗 + 网申代投 → 拿面试）：
- **以简历润色为入口**：回指模块 4 诊断出的**这位学生的具体问题**，自然过渡到"这些正是服务老师可以帮你落地的"。
- **收口到核心服务**：在优化后的简历基础上，通过**人工选岗（智能圈岗）**匹配对口岗位、由**网申代投**把简历投出去拿面试。
- **可点到现成方案**：按 `service-offerings.md`，自然提到有两档服务可选——
  **笔面试冲刺包**（偏投递+内推，适合方向较明确、想尽快投递的）、**全流程托管尊享班**（全流程系统陪跑+笔面试训练，
  适合冲央国企/大厂的）；**只点名字 + 一句话定位，不堆清单、不写价目表**，具体配置与报价交给服务老师按情况谈。

写作要点（**自然、不像广告是硬要求**）：
- 自然过渡，从模块 4 诊断引出，不要硬转、不要喊"立即购买/限时优惠"。
- 简历润色是"钩子"，落点是选岗+代投——避免只停在"帮你改简历"而不接后续投递。
- 两档方案**点到为止**：让学生知道"有两档、各适合谁"即可，**不逐条罗列服务、不放价格表**。
- 不做保证性承诺、不制造焦虑，引导保持克制（见 `report-style-guide.md` 转化逻辑）。
- 简洁，不超过 200 字。

**收尾方式（务必照做）**：模块结尾用一句**自然的中性引导句**收口，例如
"更详细的方案内容与报价，可以直接联系您的服务老师了解、按你的情况定。"
**绝不出现方括号占位说明、"待业务方补充""占位骨架"之类的字样**——交付给学生的报告里不能有任何半成品痕迹。
（页眉品牌用 `assets/logo.png`「找北求职」；具体联系方式由服务老师在沟通中提供，报告正文不强行编造。）
