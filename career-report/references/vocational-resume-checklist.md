# 简历诊断清单 — 专科 / 高职 口径（vocational track）

> 仅用于专科 / 高职 track（模块 5）。本科走 `resume-checklist.md`。
> 核心差异：专科简历**重证书、重实操、重对口实习，弱化 GPA / 论文 / 学术**。
> HR 看专科简历，第一眼找的是"有没有对口的硬证书、能不能上手干活"。

诊断方法同本科：从下列条目中筛出该学生**实际存在**的 3-5 个问题，
每条给"问题是什么 → 为什么影响求职 → 具体怎么改"，必须指向简历**具体内容**，不泛泛而谈。

---

## 模块一：证书与技能资质（专科最硬通货，优先级最高）

1. **缺对口职业资格 / 技能等级证**
   - 影响：专科求职证书是敲门砖，缺对口证（如护士执业资格、电工证、会计证、教师资格、
     CAD/BIM、1+X 职业技能等级证、Adobe、计算机等级、英语等级等）会被直接刷。
   - 改法：列出该专业 / 目标岗最该考的 1-3 个证，给出考取建议（接模块 7 时间线）。

2. **证书埋没在简历末尾 / 没分级**
   - 影响：HR 扫简历几秒，硬证书放末尾等于没有。
   - 改法：**证书单独成栏、靠前呈现**；技能注明熟练度（精通/熟练/了解）与对应设备/软件。

## 模块二：顶岗实习 / 对口实习（专科普遍有，最容易写废）

3. **顶岗实习只写岗位名、没写实操内容**
   - 影响："在 XX 厂顶岗实习"等于什么都没说，看不出会干什么。
   - 改法：写清**操作了什么设备/工艺/系统、负责什么环节、有无产出或数据**（如"独立操作 XX 数控机床，
     日均加工 XX 件，良品率 XX%"）。用具体动作 + 数字替代空泛职责。

4. **实习与目标岗不对口 / 无实习**
   - 影响：方向散或零实习，竞争力弱。
   - 改法：力争一段对口顶岗 / 实习；已有不对口实习则提炼可迁移的实操能力。

## 模块三：实训项目与技能大赛（专科的"项目经历"）

5. **有实训 / 技能大赛但没写出来**
   - 影响：校内实训、技能竞赛是专科证明动手能力的好材料，漏写可惜。
   - 改法：把代表性实训项目、技能大赛获奖（即使校级）写成条目，说明做了什么、用到什么技能。

## 模块四：求职定位与结构

6. **方向不清 / 简历无定位**
   - 影响：HR 不知往哪个岗匹配。
   - 改法：定 1 个主攻工种，把对口证书、实习、技能前置，做成方向明确的一版。

7. **套用本科简历模板、强行写 GPA / 学术**
   - 影响：专科简历堆 GPA、课程论文反而稀释了证书和实操的存在感。
   - 改法：删掉无关学术内容，腾出版面给证书、顶岗实习、技能。

## 模块五：升学并行场景（若学生走专升本）

8. **走升学但没准备"就业保底简历"**
   - 影响：只押升学、不备就业简历，专升本失败时被动（见 `report-structure-vocational.md` 模块 3）。
   - 改法：在备考同时，按上面 1-7 条整理一版可随时投递的就业简历，作保底。
