# 报告风格与话术指南

## 读者画像
主要读者：大学生本人，部分情况下家长也会阅读。
阅读场景：求职焦虑期，希望获得专业指导和信心。

## 语气原则
1. **专业但不居高临下**：用数据和逻辑说话，不用"你应该""你必须"
2. **诚实但有建设性**：指出问题时同步给出解决方案，不只泼冷水
3. **平衡而非一味乐观**：不说"企业抢着要""完全不存在问题"这类断言，
   而是说"在同层次求职者中具有竞争力""市场需求较为旺盛但竞争同样激烈"
4. **数据驱动**：尽量用具体数字而非模糊形容词。
   不说"薪资很高"，说"该方向应届生薪资中位数约 12-15k/月"
5. **不制造虚假紧迫感**：不用"再不行动就来不及了"的话术，
   而是客观说明时间窗口和节奏建议

## 措辞禁忌
- 避免："企业抢着要""稀缺人才""完全没问题""不好就业不存在"
- 避免：对学校/专业做绝对化的好坏判断
- 避免：承诺具体薪资数字（用区间）
- 避免：承诺"保就业""包入职"等保证性话术
- 避免：在中文里夹生英文词（如"您的 competitiveness 处于…"）。有对应中文就用中文（"竞争力"）；
  专有名词/技术栈（Java、Spring Boot、GPA）保留原文即可。
- **不要在报告末尾加"生成说明 / 技能署名 / 免责声明"之类的脚注**（如"本报告由 xx 技能生成…仅供参考…"）。
  这是给学生看的成品，不能暴露内部工具名，也不需要这类机器味的免责尾巴。数据时效性提示已放在报告开头的引言里，足够了。
  报告以模块 7 自然收尾即可。

## 转化逻辑（报告末尾）
报告最后一个模块是服务介绍衔接。逻辑链是：
分析了你的情况 → 指出了可优化的地方 → 这些优化我们可以帮你做 → 落地到投递拿面试

> **具体服务方案见 `references/service-offerings.md`**（两档：笔面试冲刺包 / 全流程托管尊享班，业务方提供）。
> 该文件已写明"自然、不像广告"的硬性写法：**正文不堆清单、不放价目表，只点方案名字 + 一句话定位，
> 报价交给服务老师**。承接时务必遵守。

**入口：简历润色；落点：网申代投 / 智能圈岗。**
模块 4（简历诊断）已客观列出该学生简历的具体问题，这为简历润色"创造了需求"。
因此模块 7 以简历润色作为入口——**回指模块 4 诊断出的具体问题**（如"您简历中提到的 XX 项目缺少量化成果、技能描述过于笼统"），
再自然过渡到"这些正是我们的服务老师可以帮您优化的"。
但简历润色只是钩子，**落点要收口到公司核心服务**：在优化后的简历基础上，通过智能圈岗匹配对口岗位、
由网申代投把简历投到企业，让改好的简历真正投出去拿面试。
面试辅导、会员权益等作为次要承接，简要带过即可。

注意分工：
- **模块 4 只做诊断，不出现任何推销字眼**——诊断越客观专业，模块 7 的承接越有说服力
- **所有转化话术集中在模块 7**，不在报告中间任何位置插入销售内容
- **不要把简历润色写成独立标价产品**，它是入口，公司变现在网申/圈岗/会员
- 引导保持克制：用"我们可以帮你"而非"你必须找我们"，不制造焦虑、不做保证性承诺

## 格式要求
- 使用清晰的标题层级（# ## ###）
- 关键数据和结论加粗
- **各模块篇幅以 `templates/report-structure.md` 中每个模块标注的字数为准**
  （范围约 100-500 字/模块，不要统一成同一字数）
- 总报告长度约 1800-2600 字（即各模块篇幅之和），不要为凑字数注水
