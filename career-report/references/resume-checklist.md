# 简历诊断 Checklist

## 使用说明
逐项检查用户简历，命中的问题纳入报告的"简历诊断"模块。
每个问题附带：问题描述 + 影响说明 + 改进建议。
不要列出所有条目，只列出该用户实际存在的问题（通常 3-5 条）。

## 教育背景模块
- [ ] GPA 未写明或偏低（<3.0/4.0 或 <75/100）
      影响：部分企业有 GPA 筛选线
      建议：如果 GPA 不突出，可以写专业排名百分比（如前 30%）；
            如果确实偏低，建议不写具体数字，用项目/竞赛弥补
- [ ] 未标注学校层次（211/985/双一流）
      影响：HR 快速筛选时可能误判
      建议：在学校名称后括号标注（如：河北工业大学（211））

## 技术栈/技能模块
- [ ] 技能描述过于笼统（如只写"熟悉 Java"）
      影响：无法判断掌握深度
      建议：用"掌握/熟悉/了解"分级 + 具体框架版本
            例："熟悉 Java，掌握 Spring Boot、MyBatis，了解 Spring Cloud"
- [ ] 技能列表过长（>15 项），没有重点
      影响：显得什么都会但什么都不精
      建议：按目标岗位要求精选 8-10 项核心技能，分主次排列
- [ ] 缺少目标岗位的关键技能
      影响：可能被 ATS（简历筛选系统）过滤
      建议：对照目标岗位 JD 补充关键词

## 项目经历模块
- [ ] 项目描述只写了"做了什么"，没写"结果/成果"
      影响：无法体现个人贡献和能力
      建议：用 STAR 法则重写：情境→任务→行动→结果
            例：不要写"负责用户模块开发"
            要写"独立设计并实现用户模块，包含注册/登录/权限管理，
            支撑 5000+ DAU，接口响应时间 <50ms"
- [ ] 项目全部是课程作业，没有实战项目
      影响：竞争力弱于有实习/开源项目的同学
      建议：选一个课程项目深入扩展为完整项目，部署上线；
            或参与开源项目贡献；或做一个解决真实问题的 side project
- [ ] 项目描述中没有体现个人角色（团队项目）
      影响：面试官无法判断你具体做了什么
      建议：明确标注"个人负责：xxx"，量化个人贡献

## 实习经历模块
- [ ] 没有任何实习经历
      影响：对求职而言，无实习经历是明显短板（尤其临近或已过毕业季时）
      建议：优先找 1-3 个月的短期实习快速补上；
            如果暂时找不到实习，用高质量项目 + 竞赛弥补
- [ ] 实习描述过于简单（一两句话带过）
      影响：浪费了最有说服力的经历
      建议：每段实习写 3-5 条具体工作内容和成果

## 整体结构模块
- [ ] 简历超过一页
      影响：应届生简历超一页会被视为不专业
      建议：精简到一页，删除与目标岗位无关的内容
- [ ] 没有针对目标岗位定制
      影响：投不同方向用同一份简历，匹配度低
      建议：每个方向准备一份针对性简历，突出相关经验
