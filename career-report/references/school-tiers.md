# 学校分档与市场认知表

## 使用说明
根据用户的毕业院校，在下表中查找对应梯队。
如果学校不在表中，按以下规则处理：
- 有"211""985""双一流"标签的 → 参照对应梯队的通用描述
- 普通一本 → 使用 T4 描述
- 二本/三本 → 使用 T5 描述
- 海外院校 → 单独说明，不使用此分档表

> 注意：报告中**不要暴露分档编号**（不说"你属于 T3"），只使用各梯队的市场认知描述。

> 口径说明：985 / 211 / 双一流名单为官方固定事实，已逐校核对（见文末「数据来源与核验」）。
> 凡涉及"强 / 弱 / 接近某档"等主观判断，均附排名或就业证据并标注来源；无证据的主观判断不写入。

## 梯队定义

### T1：顶尖院校（C9 联盟，9 所）
清华大学、北京大学、浙江大学、复旦大学、上海交通大学、
南京大学、中国科学技术大学、哈尔滨工业大学、西安交通大学

市场认知：所有城市所有企业类型均为最优先级，大厂/外企/国企均高度认可。
薪资定位：同岗位薪资通常在 P75 以上。
求职建议要点：重点是方向选择和平台选择，而非"能不能找到工作"。

市场认知：一线城市大厂、中大型企业高度认可，薪资和晋升通道明显优于非 985。
薪资定位：同岗位薪资通常在 P50-P75。
求职建议要点：学历是明确优势，重点是技能匹配和项目经验的丰富度。

> 海洋/水产、西农的农林、央民的民族学）仍有很强认可度，不可一概而论；③ 报告中不要直接说
> "你的学校在 985 里偏弱"，而应结合目标城市与岗位客观表述。

### T4：普通一本
**判定规则（无固定名单，按规则归档）：**
- 省属重点本科、普通一本院校（非 211/双一流）
- 学校名称含"大学/学院"，本省一本批次招生，但无 985/211/双一流标签
- 例：多数省属综合性大学、行业普通本科院校

市场认知：中小企业认可，大厂需要较强的项目/竞赛背景弥补。
薪资定位：同岗位薪资通常在 P25-P50。
求职建议要点：需要突出个人技术能力和项目实战经验，学历不是核心竞争力。

### T5：二本及以下
**判定规则（无固定名单，按规则归档）：**
- 二本批次招生的普通本科院校
- 独立学院、民办本科、三本院校
- 专科/高职（如目标是技术岗，参考此档并强调作品与实操能力）

市场认知：需要用作品、证书、实习经历来建立竞争力。
薪资定位：同岗位薪资通常在 P25 以下。
求职建议要点：降低对大厂的预期，优先考虑中小企业的技术岗作为起步。

## 兜底与边界情况
- **学校不在以上任何列表**：按"使用说明"的规则归档（看 985/211/双一流标签 → 普通一本 →
  二本），**不要编造该校的具体梯队或排名**。
- **改名/合并院校**：按当前名称对应的层次判断。
- **中外合作办学机构**（如宁波诺丁汉、西交利物浦）：单独说明办学性质，不强行套用本表分档。
- **海外院校**：不使用本表，参考目标城市对该校 QS/THE 排名段的普遍认知另行说明。
